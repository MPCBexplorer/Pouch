### 2.1.1 关于 `com.sun.net.httpserver`

包名带 `com.sun.` 前缀，容易让人以为是内部 API。**它不是**——`jdk.httpserver` 模块明确导出 `com.sun.net.httpserver` 包，自 Java 6 起稳定存在，可放心使用。编译时不需要 `--add-exports`。

需要知道的能力边界：

- ✅ 提供 `HttpServer`、`HttpContext`、`HttpExchange`，支持路径前缀匹配、线程池执行器
- ✅ 支持 chunked 传输、自定义响应头
- ❌ **不提供路由参数解析**（`/api/records/{id}` 这种模板匹配要自己写）→ 见 §2.4 `Router`
- ❌ **不提供请求体自动反序列化** → 见 §2.4 的 `readBody` 辅助方法
- ❌ 不支持 HTTP/2、WebSocket → 本项目用不到

### 2.1.2 获取 Gson

手动下载 `gson-2.11.0.jar` 放入 `server/lib/`。三种途径任选：

1. Maven Central 直接下载：`https://repo1.maven.org/maven2/com/google/code/gson/gson/2.11.0/gson-2.11.0.jar`
2. 若本机有 Maven（当前没有）：`mvn dependency:get -Dartifact=com.google.code.gson:gson:2.11.0`
3. 从任意已有 Java 项目的本地仓库复制：`%USERPROFILE%\.m2\repository\com\google\code\gson\gson\2.11.0\`

**校验**：文件大小应约 283 KB。放入后 `server/lib/` 目录只有这一个 jar。

> 若确实无法获取 Gson，可退化为 JDK 无依赖方案——但需要自己写 JSON 解析/序列化，约 400 行代码且易出错。**不建议**。文档其余部分假定 Gson 可用。

### `Category.java`

```java
package com.pouch.model;

/**
 * 四个记录类别。文件名映射的唯一权威来源——
 * 代码中任何位置都不得硬编码 "todos.json" 之类的字符串。
 */
public enum Category {
    INSPIRATION("inspiration", "灵感",        "inspirations.json"),
    QUESTION   ("question",    "问题",        "questions.json"),
    KNOWLEDGE  ("knowledge",   "碎片知识",    "knowledge.json"),
    TODO       ("todo",        "要做的事",    "todos.json");

    private final String wire;       // API 与 JSON 中的取值
    private final String label;      // 界面显示名
    private final String fileName;   // 数据文件名

    Category(String wire, String label, String fileName) {
        this.wire = wire;
        this.label = label;
        this.fileName = fileName;
    }

    public String wire()     { return wire; }
    public String label()    { return label; }
    public String fileName() { return fileName; }

    /** 由 API 字符串解析；非法值抛 IllegalArgumentException（Handler 转 400 invalid_type）。 */
    public static Category fromWire(String s) {
        for (Category c : values()) if (c.wire.equals(s)) return c;
        throw new IllegalArgumentException("unknown type: " + s);
    }

    /** 该类别的合法状态集合。 */
    public java.util.Set<String> allowedStatuses() {
        return switch (this) {
            case INSPIRATION -> java.util.Set.of("active", "archived");
            case QUESTION    -> java.util.Set.of("open", "resolved");
            case KNOWLEDGE   -> java.util.Set.of("learning", "mastered");
            case TODO        -> java.util.Set.of("open", "done", "cancelled");
        };
    }

    /** 创建时的默认状态。 */
    public String defaultStatus() {
        return switch (this) {
            case INSPIRATION -> "active";
            case QUESTION    -> "open";
            case KNOWLEDGE   -> "learning";
            case TODO        -> "open";
        };
    }

    /** 「完成/未完成」饼图的归口：done 片 / open 片 / 不计入（null）。 */
    public String completionBucket(String status) {
        if (this != TODO) return null;
        return switch (status) {
            case "done" -> "done";
            case "open" -> "open";
            default     -> null;   // cancelled 不计入，见 01 §1.4.1
        };
    }
}
```

> **`completionBucket` 集中了 ADR-004 与 01 §1.4.1 的口径**。统计逻辑不得在别处重新判断 `"done".equals(status)`——一旦口径要改（比如把 cancelled 算进未完成），只改这一个方法。

### `JsonStore.java`

**职责**：文件读写、锁、原子写、备份、内存索引。**不做业务校验，不认识 HTTP**。

```java
package com.pouch.store;

import com.google.gson.*;
import com.pouch.model.*;

import java.io.IOException;
import java.nio.charset.StandardCharsets;
import java.nio.file.*;
import java.nio.file.attribute.BasicFileAttributes;
import java.time.OffsetDateTime;
import java.time.format.DateTimeFormatter;
import java.util.*;
import java.util.concurrent.locks.ReentrantReadWriteLock;

public class JsonStore {

    /** 单文件容器：内存索引 + 独立读写锁。 */
    private static final class FileSlot<T> {
        final Map<String, T> byId = new LinkedHashMap<>();  // 保持文件顺序
        final ReentrantReadWriteLock lock = new ReentrantReadWriteLock();
        final Path path;
        final String arrayField;   // "records" 或 "items"

        FileSlot(Path path, String arrayField) {
            this.path = path; this.arrayField = arrayField;
        }
    }

    private static final int VERSION = 1;
    private static final int BACKUP_KEEP = 50;
    private static final DateTimeFormatter STAMP =
            DateTimeFormatter.ofPattern("yyyyMMdd-HHmmss-SSS");

    private final Path dataDir;
    private final Path backupDir;
    private final Gson gson;

    private final Map<Category, FileSlot<Record>> recordSlots = new EnumMap<>(Category.class);
    private final FileSlot<WishItem> wishSlot;

    public JsonStore(Path dataDir) {
        this.dataDir = dataDir.toAbsolutePath().normalize();
        this.backupDir = this.dataDir.resolve(".backup");
        this.gson = new GsonBuilder()
                .setPrettyPrinting()      // 人工可读，这是本方案的核心优势之一
                .disableHtmlEscaping()    // 不转义 = > &，否则 Markdown 正文会被改写成 \u003d
                .create();                // 不调 serializeNulls()，见下方说明

        for (Category c : Category.values()) {
            recordSlots.put(c, new FileSlot<>(this.dataDir.resolve(c.fileName()), "records"));
        }
        this.wishSlot = new FileSlot<>(this.dataDir.resolve("wishlist.json"), "items");
    }
```

> **`disableHtmlEscaping()` 不可省略**：Gson 默认会把 `=`、`>`、`<`、`&` 转义成 `\u003d` 这类形式。正文是 Markdown，充满这些字符，转义后文件将完全无法人工阅读——而"人工可编辑"正是本方案的核心优势。
>
> **不要调用 `serializeNulls()`**：ADR-003 要求"类别专有字段为 null 时不落盘"，靠的正是 Gson 的默认行为。若开启它，每条灵感都会带上 `"subject": null, "dueDate": null, "priority": null, "doneAt": null, "source": null` 五个垃圾字段，文件体积翻倍且难以阅读。`Note.updatedAt` 同理，未编辑时不应出现在文件中。

```java
    /** 启动加载。任一文件损坏不致命，走 01 §1.7.5 的恢复流程。 */
    public void load() throws IOException {
        Files.createDirectories(dataDir);
        Files.createDirectories(backupDir);

        for (Category c : Category.values()) {
            FileSlot<Record> slot = recordSlots.get(c);
            loadSlot(slot, Record.class, c.label() + "（" + c.fileName() + "）");
        }
        loadSlot(wishSlot, WishItem.class, "心愿单（wishlist.json）");

        detectDuplicateIds();   // 01 §1.8.1 的兜底检测
    }

    /**
     * 载入单个数据文件。
     *
     * ★ 锁语义说明：本方法只在 load() 中调用，而 load() 运行于 HttpServer.start() 之前，
     *   即整个进程的单线程启动阶段——此时不可能有并发访问，因此无需持有写锁。
     *   index() 内部的加锁是防御性的（保证将来若被别处复用仍正确），不是必需。
     *   但 writeSlotUnsafe() 的契约是"调用方负责串行化"，在这里由"启动阶段单线程"这一事实满足。
     */
    private <T> void loadSlot(FileSlot<T> slot, Class<T> elemType, String humanName) {
        if (!Files.exists(slot.path)) {
            System.out.println("[init] " + humanName + " 不存在，将创建空文件");
            try { writeSlotUnsafe(slot, elemType); }
            catch (IOException e) { throw new StoreException("无法创建 " + slot.path, e); }
            return;
        }

        String json;
        try { json = Files.readString(slot.path, StandardCharsets.UTF_8); }
        catch (IOException e) { throw new StoreException("无法读取 " + slot.path, e); }

        List<T> parsed = tryParse(json, elemType, slot.arrayField);
        if (parsed != null) { index(slot, parsed, idExtractor(elemType)); return; }

        // 解析失败 → 从备份恢复
        System.err.println("[WARN] " + humanName + " 解析失败，尝试从备份恢复…");
        List<Path> backups = listBackups(slot.path, true);   // 新→旧
        for (Path b : backups) {
            try {
                List<T> p = tryParse(Files.readString(b, StandardCharsets.UTF_8),
                                     elemType, slot.arrayField);
                if (p != null) {
                    quarantine(slot.path);   // 损坏文件改名保留，不删除
                    System.err.println("[WARN] ✓ 已从备份 " + b.getFileName() + " 恢复 "
                            + humanName + "（" + p.size() + " 条）。"
                            + "原损坏文件保留为 " + slot.path.getFileName() + ".corrupt");
                    index(slot, p, idExtractor(elemType));
                    writeSlotUnsafe(slot, elemType);   // 把恢复结果落到主文件
                    return;
                }
            } catch (IOException ignored) { /* 试下一份 */ }
        }

        System.err.println("[WARN] ✗ " + humanName + " 无任何可用备份，本类别以空数据启动。"
                + "服务继续运行，其余类别不受影响。");
        quarantine(slot.path);
        index(slot, List.of(), idExtractor(elemType));
    }

    /** 解析顶层对象并取出数组；任何异常都返回 null（表示失败）。 */
    private <T> List<T> tryParse(String json, Class<T> elemType, String arrayField) {
        try {
            JsonObject root = JsonParser.parseString(json).getAsJsonObject();
            JsonElement arr = root.get(arrayField);
            if (arr == null || !arr.isJsonArray()) return null;
            List<T> out = new ArrayList<>();
            for (JsonElement e : arr.getAsJsonArray()) out.add(gson.fromJson(e, elemType));
            return out;
        } catch (JsonParseException | IllegalStateException e) {
            return null;
        }
    }

    private <T> java.util.function.Function<T, String> idExtractor(Class<T> t) {
        if (t == Record.class)   return r -> ((Record) r).id();
        if (t == WishItem.class) return w -> ((WishItem) w).id();
        throw new IllegalArgumentException("unsupported type " + t);
    }

    private <T> void index(FileSlot<T> slot, List<T> items,
                           java.util.function.Function<T, String> idOf) {
        slot.lock.writeLock().lock();
        try {
            slot.byId.clear();
            for (T it : items) {
                String id = idOf.apply(it);
                if (id == null || id.isBlank()) {
                    System.err.println("[WARN] 跳过一条缺少 id 的数据：" + it);
                    continue;
                }
                if (slot.byId.put(id, it) != null) {
                    System.err.println("[WARN] 文件内发现重复 id " + id + "，保留后出现的一条");
                }
            }
        } finally { slot.lock.writeLock().unlock(); }
    }

    /** 把损坏文件改名为 .corrupt 保留（不删除，供人工排查）。 */
    private void quarantine(Path p) {
        try {
            Path target = p.resolveSibling(p.getFileName() + ".corrupt");
            Files.move(p, target, StandardCopyOption.REPLACE_EXISTING);
        } catch (IOException e) {
            System.err.println("[WARN] 无法隔离损坏文件 " + p + "：" + e.getMessage());
        }
    }

    /** 跨文件重复 id 检测（01 §1.8.1 的兜底）。 */
    private void detectDuplicateIds() {
        Map<String, Category> seen = new HashMap<>();
        for (Category c : Category.values()) {
            for (String id : recordSlots.get(c).byId.keySet()) {
                Category prev = seen.put(id, c);
                if (prev != null) {
                    System.err.println("[WARN] 记录 " + id + " 同时存在于 "
                            + prev.fileName() + " 和 " + c.fileName()
                            + "（可能是变更类别时写入中断）。请人工检查并删除多余的一份。");
                }
            }
        }
    }
```

**读取快照**——所有对外暴露的集合都必须是不可变副本：

```java
    /** 返回某类别全部记录的不可变快照（读锁内复制）。 */
    public List<Record> all(Category c) {
        FileSlot<Record> slot = recordSlots.get(c);
        slot.lock.readLock().lock();
        try { return List.copyOf(slot.byId.values()); }
        finally { slot.lock.readLock().unlock(); }
    }

    /** 按 id 取单条；不存在返回 Optional.empty()。 */
    public Optional<Record> find(Category c, String id) {
        FileSlot<Record> slot = recordSlots.get(c);
        slot.lock.readLock().lock();
        try { return Optional.ofNullable(slot.byId.get(id)); }
        finally { slot.lock.readLock().unlock(); }
    }
```

**写入**——六个语义明确的方法（记录三个 + 心愿三个）。每个都保证"改内存 + 原子写盘"在同一把写锁内完成，外部代码不得直接触碰 `byId`：

```java
    /**
     * 新增一条记录并落盘。
     * 写盘失败时回滚内存索引，保证内存与磁盘不脱节——
     * 否则会出现"内存里有、文件里没有"的幽灵数据，重启后消失。
     */
    public void insertRecord(Category c, Record r) {
        FileSlot<Record> slot = recordSlots.get(c);
        slot.lock.writeLock().lock();
        try {
            if (slot.byId.containsKey(r.id())) {
                throw new StoreException("id 已存在：" + r.id());
            }
            slot.byId.put(r.id(), r);
            try {
                writeSlotUnsafe(slot, Record.class);
            } catch (IOException e) {
                slot.byId.remove(r.id());          // 回滚
                throw new StoreException("写入 " + slot.path + " 失败：" + e.getMessage(), e);
            }
        } finally { slot.lock.writeLock().unlock(); }
    }

    /** 修改一条已存在的记录并落盘。找不到返回 false（不抛异常，由 Service 转 404）。 */
    public boolean updateRecord(Category c, String id,
                                java.util.function.Consumer<Record> mutator) {
        FileSlot<Record> slot = recordSlots.get(c);
        slot.lock.writeLock().lock();
        try {
            Record r = slot.byId.get(id);
            if (r == null) return false;
            mutator.accept(r);
            writeSlotUnsafe(slot, Record.class);
            return true;
        } catch (IOException e) {
            throw new StoreException("写入 " + slot.path + " 失败：" + e.getMessage(), e);
        } finally { slot.lock.writeLock().unlock(); }
    }

    /** 删除一条记录并落盘。找不到返回 false。 */
    public boolean deleteRecord(Category c, String id) {
        FileSlot<Record> slot = recordSlots.get(c);
        slot.lock.writeLock().lock();
        try {
            Record removed = slot.byId.remove(id);
            if (removed == null) return false;
            try {
                writeSlotUnsafe(slot, Record.class);
            } catch (IOException e) {
                slot.byId.put(id, removed);        // 回滚：把删掉的放回去
                throw new StoreException("写入 " + slot.path + " 失败：" + e.getMessage(), e);
            }
            return true;
        } finally { slot.lock.writeLock().unlock(); }
    }

    /** 记录是否存在（供 RecordHandler 跨类别查找 id 用，见 §2.6）。 */
    public boolean existsRecord(Category c, String id) {
        FileSlot<Record> slot = recordSlots.get(c);
        slot.lock.readLock().lock();
        try { return slot.byId.containsKey(id); }
        finally { slot.lock.readLock().unlock(); }
    }

    // WishItem 的三个方法结构完全相同，仅 slot 换为 wishSlot、类型换为 WishItem：
    public void insertWish(WishItem w) { /* 同 insertRecord */ }
    public boolean updateWish(String id, java.util.function.Consumer<WishItem> mutator) { /* 同 updateRecord */ }
    public boolean deleteWish(String id) { /* 同 deleteRecord */ }
```

> **`updateRecord` 没有回滚**，而 `insertRecord` / `deleteRecord` 有。这不是疏漏：`mutator.accept(r)` 直接改的是内存中的对象引用，写盘失败时对象已处于半修改状态，无法自动回滚。
>
> **应对方式**：`updateRecord` 抛出的 `StoreException` 会被 `BaseHandler` 转成 500，前端提示"保存失败"。由于写盘失败极罕见（磁盘满/权限问题），且**磁盘上的文件仍是修改前的完好状态**，用户刷新页面会看到旧数据、重新编辑即可。这是可接受的降级，不必为此实现深拷贝快照——那会让每次 PATCH 都多一次完整对象复制。

**原子写盘**（01 §1.7.2 的实现）：

```java
    /** 备份 + 序列化 + 临时文件 + force + 原子 move。调用方必须已持有写锁。 */
    private <T> void writeSlotUnsafe(FileSlot<T> slot, Class<T> elemType) throws IOException {
        // 1. 备份当前文件（存在且非空才备份）
        if (Files.exists(slot.path)) {
            BasicFileAttributes attr = Files.readAttributes(slot.path, BasicFileAttributes.class);
            if (attr.size() > 0) backup(slot.path);
        }

        // 2. 在内存中完成序列化——失败则不动磁盘，原文件完好
        JsonObject root = new JsonObject();
        root.addProperty("version", VERSION);
        root.addProperty("updatedAt", nowIso());
        JsonArray arr = new JsonArray();
        for (T item : slot.byId.values()) arr.add(gson.toJsonTree(item));
        root.add(slot.arrayField, arr);
        byte[] bytes = gson.toJson(root).getBytes(StandardCharsets.UTF_8);

        // 3. 写临时文件（必须与目标同目录，保证同一文件系统）
        Path tmp = slot.path.resolveSibling("." + slot.path.getFileName() + ".tmp");
        try (var ch = java.nio.channels.FileChannel.open(tmp,
                StandardOpenOption.CREATE, StandardOpenOption.WRITE,
                StandardOpenOption.TRUNCATE_EXISTING)) {
            ch.write(java.nio.ByteBuffer.wrap(bytes));
            // 4. 强制刷盘——不可省略，否则断电可能得到"长度正确但内容全零"的文件
            ch.force(true);
        } catch (IOException e) {
            Files.deleteIfExists(tmp);   // 6. 失败清理
            throw e;
        }

        // 5. 原子替换
        try {
            Files.move(tmp, slot.path,
                    StandardCopyOption.ATOMIC_MOVE, StandardCopyOption.REPLACE_EXISTING);
        } catch (AtomicMoveNotSupportedException e) {
            // 极少数文件系统不支持 ATOMIC_MOVE，退化为普通替换（丧失原子性但可用）
            System.err.println("[WARN] 文件系统不支持原子移动，退化为普通替换：" + slot.path);
            Files.move(tmp, slot.path, StandardCopyOption.REPLACE_EXISTING);
        } catch (IOException e) {
            Files.deleteIfExists(tmp);
            throw e;
        }
    }

    private void backup(Path p) throws IOException {
        String base = p.getFileName().toString().replaceFirst("\\.json$", "");
        Path b = backupDir.resolve(base + "." + OffsetDateTime.now().format(STAMP) + ".json");
        Files.copy(p, b, StandardCopyOption.REPLACE_EXISTING);
        pruneBackups(p);
    }

    /** 每个数据文件最多保留 BACKUP_KEEP 份，删除最旧的。 */
    private void pruneBackups(Path p) throws IOException {
        List<Path> all = listBackups(p, false);   // 旧→新
        int excess = all.size() - BACKUP_KEEP;
        for (int i = 0; i < excess; i++) Files.deleteIfExists(all.get(i));
    }

    private List<Path> listBackups(Path p, boolean newestFirst) {
        String base = p.getFileName().toString().replaceFirst("\\.json$", "") + ".";
        List<Path> out = new ArrayList<>();
        try (DirectoryStream<Path> ds = Files.newDirectoryStream(backupDir, base + "*.json")) {
            ds.forEach(out::add);
        } catch (IOException | NoSuchFileException e) {
            return out;   // 备份目录不存在时返回空，不致命
        }
        out.sort((a, b) -> a.getFileName().toString().compareTo(b.getFileName().toString()));
        if (newestFirst) Collections.reverse(out);
        return out;
    }

    public static String nowIso() {
        return OffsetDateTime.now().format(DateTimeFormatter.ISO_OFFSET_DATE_TIME);
    }
}
```

> **时间格式统一走 `nowIso()`**，全代码库不得出现第二种时间格式化方式。`ISO_OFFSET_DATE_TIME` 产出 `2026-10-02T14:23:11.482+08:00`，与 01 §1.2 约定一致，且**字符串序即时间序**（同时区下），排序时可直接用 `compareTo` 而无需解析。

### 2.3.1 变更类别的跨文件写（01 §1.8.1）

```java
/** 变更记录类别：先加后删，固定加锁顺序避免死锁。 */
public boolean moveRecord(String id, Category from, Category to,
                          java.util.function.Consumer<Record> prepare) {
    if (from == to) return updateRecord(to, id, prepare);

    // 固定按枚举声明序加锁（inspiration < question < knowledge < todo）
    Category first  = from.ordinal() < to.ordinal() ? from : to;
    Category second = from.ordinal() < to.ordinal() ? to   : from;

    FileSlot<Record> s1 = recordSlots.get(first);
    FileSlot<Record> s2 = recordSlots.get(second);
    s1.lock.writeLock().lock();
    try {
        s2.lock.writeLock().lock();
        try {
            Record r = recordSlots.get(from).byId.get(id);
            if (r == null) return false;

            prepare.accept(r);                 // 改 type、补专有字段、更新 updatedAt
            r.clearForeignFields(to);

            // 先加：写入目标文件
            recordSlots.get(to).byId.put(id, r);
            writeSlotUnsafe(recordSlots.get(to), Record.class);

            // 后删：从源文件移除
            recordSlots.get(from).byId.remove(id);
            writeSlotUnsafe(recordSlots.get(from), Record.class);
            return true;
        } finally { s2.lock.writeLock().unlock(); }
    } catch (IOException e) {
        throw new StoreException("变更类别失败：" + e.getMessage(), e);
    } finally { s1.lock.writeLock().unlock(); }
}
```

> 注意 `writeSlotUnsafe` 内部会各自备份自己的文件，因此这一步会产生两份备份（源与目标各一份），符合预期。

```java
package com.pouch;

import com.google.gson.Gson;
import com.sun.net.httpserver.HttpExchange;

import java.io.IOException;
import java.io.OutputStream;
import java.nio.charset.StandardCharsets;

public final class Respond {
    private static final Gson GSON = new Gson();

    private Respond() {}

    public static void json(HttpExchange ex, int status, Object body) throws IOException {
        byte[] bytes = GSON.toJson(body).getBytes(StandardCharsets.UTF_8);
        ex.getResponseHeaders().set("Content-Type", "application/json; charset=utf-8");
        ex.getResponseHeaders().set("Cache-Control", "no-store");
        ex.sendResponseHeaders(status, bytes.length);
        try (OutputStream os = ex.getResponseBody()) { os.write(bytes); }
    }

    public static void noContent(HttpExchange ex) throws IOException {
        ex.sendResponseHeaders(204, -1);
        ex.close();
    }

    /** 统一错误信封：{ "error": { "code": "...", "message": "..." } } */
    public static void error(HttpExchange ex, int status, String code, String message) throws IOException {
        json(ex, status, java.util.Map.of("error", java.util.Map.of(
                "code", code, "message", message == null ? "" : message)));
    }
}
```

### `Router.java`

`HttpServer` 只做路径**前缀**匹配，不提供 `{id}` 模板解析，需要自己写。

```java
package com.pouch;

import com.sun.net.httpserver.HttpExchange;

import java.io.IOException;
import java.util.*;

/**
 * 极简路由：注册 (method, pattern) → handler。
 * pattern 中的 {name} 段会解析进 pathParams。
 *
 * 例：register("GET", "/api/records/{id}", (ex, p) -> ...)
 *     请求 GET /api/records/abc → p.get("id") == "abc"
 */
public class Router {

    @FunctionalInterface
    public interface Route {
        void handle(HttpExchange ex, Map<String, String> pathParams) throws IOException;
    }

    private record Entry(String method, List<String> segments) {}

    private final List<Map.Entry<Entry, Route>> routes = new ArrayList<>();
    private final com.pouch.handler.StaticHandler staticHandler;

    public Router(com.pouch.handler.StaticHandler staticHandler) {
        this.staticHandler = staticHandler;
    }

    public Router register(String method, String pattern, Route route) {
        routes.add(Map.entry(new Entry(method, split(pattern)), route));
        return this;
    }

    private static List<String> split(String path) {
        return Arrays.stream(path.split("/")).filter(s -> !s.isEmpty()).toList();
    }

    /** 注册为 HttpServer 的根 Context，接管所有请求。 */
    public void handle(HttpExchange ex) throws IOException {
        String method = ex.getRequestMethod().toUpperCase(Locale.ROOT);
        List<String> reqSegs = split(ex.getRequestURI().getPath());

        boolean pathMatched = false;
        for (var e : routes) {
            Map<String, String> params = match(e.getKey().segments(), reqSegs);
            if (params == null) continue;
            pathMatched = true;
            if (!e.getKey().method().equals(method)) continue;
            e.getValue().handle(ex, params);
            return;
        }

        if (pathMatched) {
            // 路径存在但方法不对 → 405（而非 404），便于前端排查
            ex.getResponseHeaders().set("Allow", allowedMethods(reqSegs));
            Respond.error(ex, 405, "method_not_allowed", method + " 不被此路径支持");
            return;
        }

        // 没有 API 路由匹配：GET/HEAD 交给静态资源，其余 404
        if (method.equals("GET") || method.equals("HEAD")) {
            staticHandler.serve(ex);
            return;
        }
        Respond.error(ex, 404, "not_found", "无此端点：" + method + " " + ex.getRequestURI().getPath());
    }

    /** 段级匹配：{name} 匹配任意非空段并记录；字面段需完全相等。 */
    private static Map<String, String> match(List<String> pattern, List<String> actual) {
        if (pattern.size() != actual.size()) return null;
        Map<String, String> params = new HashMap<>();
        for (int i = 0; i < pattern.size(); i++) {
            String p = pattern.get(i), a = actual.get(i);
            if (p.startsWith("{") && p.endsWith("}")) {
                params.put(p.substring(1, p.length() - 1),
                        java.net.URLDecoder.decode(a, java.nio.charset.StandardCharsets.UTF_8));
            } else if (!p.equals(a)) {
                return null;
            }
        }
        return params;
    }

    private String allowedMethods(List<String> reqSegs) {
        Set<String> ms = new TreeSet<>();
        for (var e : routes) if (match(e.getKey().segments(), reqSegs) != null) ms.add(e.getKey().method());
        return String.join(", ", ms);
    }
}
```

**请求解析辅助**（独立类 `com.pouch.Requests`，与 `Respond` 分开——一个管入、一个管出）：

```java
package com.pouch;

import com.google.gson.*;
import com.sun.net.httpserver.HttpExchange;

import java.io.IOException;
import java.net.URLDecoder;
import java.nio.charset.StandardCharsets;
import java.util.HashMap;
import java.util.Map;

/** 请求解析：一个管入（本类），一个管出（Respond）。 */
public final class Requests {

    private Requests() {}

    /** 请求体大小上限。防止畸形请求把内存打爆。 */
    private static final int MAX_BODY_BYTES = 2_000_000;   // 2 MB

    /** 读取并解析 JSON 请求体。空体返回空 JsonObject（PATCH 语义：无字段=不修改）。 */
    public static JsonObject readJsonBody(HttpExchange ex) throws IOException {
        byte[] raw;
        try (var in = ex.getRequestBody()) { raw = in.readAllBytes(); }

        if (raw.length == 0) return new JsonObject();
        if (raw.length > MAX_BODY_BYTES) {
            throw HttpError.badRequest("body_too_large", "请求体超过 2 MB 上限");
        }
        try {
            JsonElement el = JsonParser.parseString(new String(raw, StandardCharsets.UTF_8));
            if (!el.isJsonObject()) {
                throw HttpError.badRequest("invalid_json", "请求体必须是 JSON 对象");
            }
            return el.getAsJsonObject();
        } catch (JsonParseException e) {
            throw HttpError.badRequest("invalid_json", "JSON 解析失败：" + e.getMessage());
        }
    }

    /** 查询参数解析。/api/records?type=todo&page=2 → Map。重复键取最后一个。 */
    public static Map<String, String> queryParams(HttpExchange ex) {
        String q = ex.getRequestURI().getRawQuery();
        if (q == null || q.isBlank()) return Map.of();
        Map<String, String> out = new HashMap<>();
        for (String pair : q.split("&")) {
            if (pair.isEmpty()) continue;
            int i = pair.indexOf('=');
            String k = i < 0 ? pair : pair.substring(0, i);
            String v = i < 0 ? ""    : pair.substring(i + 1);
            out.put(URLDecoder.decode(k, StandardCharsets.UTF_8),
                    URLDecoder.decode(v, StandardCharsets.UTF_8));
        }
        return out;
    }
}
```

## 2.5 服务层

### `RecordService.java`

**职责**：类别相关的字段校验、查询筛选、排序分页、随机抽取。**不碰文件，不认识 HTTP**（异常用 `HttpError` 抛出是为了让 Handler 少写转换代码，可接受的耦合）。

```java
package com.pouch.service;

import com.pouch.HttpError;
import com.pouch.model.*;
import com.pouch.store.JsonStore;

import java.time.LocalDate;
import java.time.format.DateTimeParseException;
import java.util.*;
import java.util.stream.Collectors;

public class RecordService {

    private final JsonStore store;
    private final Random random = new Random();

    public RecordService(JsonStore store) { this.store = store; }

    // ================= 创建 =================

    public Record create(Category c, Map<String, Object> in) {
        Record r = new Record();
        r.setId(UUID.randomUUID().toString());
        r.setType(c.wire());
        String now = JsonStore.nowIso();
        r.setCreatedAt(now);
        r.setUpdatedAt(now);

        r.setTitle(requireTitle(in));
        r.setContent(str(in.get("content"), ""));
        r.setTags(normalizeTags(in.get("tags")));
        r.setNotes(new ArrayList<>());
        r.setStatus(resolveStatus(c, in.get("status")));
        r.setPinned(bool(in.get("pinned"), false));

        applyTypeSpecific(c, r, in, true);
        store.insertRecord(c, r);
        return r;
    }

    // ================= 更新 =================

    /** PATCH 语义：只处理请求中出现的字段。 */
    public Record update(Category c, String id, Map<String, Object> patch) {
        Record existing = store.find(c, id)
                .orElseThrow(() -> HttpError.notFound("record_not_found", "找不到记录 " + id));

        // 状态变更需先校验（涉及 doneAt 联动）
        String newStatus = patch.containsKey("status")
                ? resolveStatus(c, patch.get("status")) : existing.status();

        boolean ok = store.updateRecord(c, id, r -> {
            if (patch.containsKey("title"))   r.setTitle(requireTitle(patch));
            if (patch.containsKey("content")) r.setContent(str(patch.get("content"), ""));
            if (patch.containsKey("tags"))    r.setTags(normalizeTags(patch.get("tags")));
            if (patch.containsKey("pinned"))  r.setPinned(bool(patch.get("pinned"), false));

            if (!Objects.equals(newStatus, r.status())) {
                r.setStatus(newStatus);
                // doneAt 联动：todo 转 done 时写入，转离 done 时清空
                if (c == Category.TODO) {
                    r.setDoneAt("done".equals(newStatus) ? JsonStore.nowIso() : null);
                }
            }
            applyTypeSpecific(c, r, patch, false);
            r.setUpdatedAt(JsonStore.nowIso());
        });
        if (!ok) throw HttpError.notFound("record_not_found", "找不到记录 " + id);
        return store.find(c, id).orElseThrow();
    }

    // ================= 校验 =================

    private String requireTitle(Map<String, Object> in) {
        Object v = in.get("title");
        if (v == null) throw HttpError.badRequest("invalid_title", "title 为必填项");
        String s = String.valueOf(v).trim();
        if (s.isEmpty())            throw HttpError.badRequest("invalid_title", "title 不能为空");
        if (s.length() > 120)       throw HttpError.badRequest("invalid_title", "title 不得超过 120 字符");
        return s;
    }

    private String resolveStatus(Category c, Object v) {
        if (v == null) return c.defaultStatus();
        String s = String.valueOf(v).trim();
        if (!c.allowedStatuses().contains(s)) {
            throw HttpError.badRequest("invalid_status",
                    c.wire() + " 的合法状态为 " + c.allowedStatuses() + "，收到：" + s);
        }
        return s;
    }

    /** 类别专有字段的校验与赋值。creating=true 时执行必填检查。 */
    private void applyTypeSpecific(Category c, Record r, Map<String, Object> in, boolean creating) {
        switch (c) {
            case KNOWLEDGE -> {
                Object s = in.get("subject");
                if (s != null) r.setSubject(validateSubject(String.valueOf(s)));
                else if (creating) throw HttpError.badRequest("invalid_subject",
                        "碎片知识必须指定 subject（学科）");
                if (in.containsKey("source")) r.setSource(validateShort(in.get("source"), "source", 200));
            }
            case QUESTION -> {
                if (in.containsKey("source")) r.setSource(validateShort(in.get("source"), "source", 200));
            }
            case TODO -> {
                if (in.containsKey("dueDate"))  r.setDueDate(validateDueDate(in.get("dueDate")));
                if (in.containsKey("priority")) r.setPriority(validatePriority(in.get("priority")));
            }
            case INSPIRATION -> { /* 无专有字段 */ }
        }
        // 不适用的类别上清除专有字段（宽容读取，见 01 §1.9）
        r.clearForeignFields(c);
    }

    /** 学科：1~3 层，每层 trim 后 1~20 字符，以 / 分隔。 */
    private String validateSubject(String raw) {
        String s = raw.trim();
        if (s.isEmpty()) throw HttpError.badRequest("invalid_subject", "subject 不能为空");
        String[] parts = s.split("/", -1);
        if (parts.length > 3) throw HttpError.badRequest("invalid_subject", "subject 最多 3 层");
        List<String> clean = new ArrayList<>();
        for (String p : parts) {
            String t = p.trim();
            if (t.isEmpty() || t.length() > 20) {
                throw HttpError.badRequest("invalid_subject", "subject 每层须为 1~20 字符：" + s);
            }
            clean.add(t);
        }
        return String.join("/", clean);
    }

    private String validateDueDate(Object v) {
        if (v == null) return null;
        String s = String.valueOf(v).trim();
        if (s.isEmpty()) return null;
        try { return LocalDate.parse(s).toString(); }   // 归一化，拒绝 2026-13-45 这类
        catch (DateTimeParseException e) {
            throw HttpError.badRequest("invalid_due_date", "dueDate 须为 yyyy-MM-dd 格式：" + s);
        }
    }

    private String validatePriority(Object v) {
        if (v == null) return null;
        String s = String.valueOf(v).trim().toLowerCase(Locale.ROOT);
        if (s.isEmpty()) return "normal";
        if (!Set.of("low", "normal", "high").contains(s)) {
            throw HttpError.badRequest("invalid_priority", "priority 须为 low/normal/high：" + s);
        }
        return s;
    }

    private String validateShort(Object v, String field, int max) {
        if (v == null) return null;
        String s = String.valueOf(v).trim();
        if (s.length() > max) throw HttpError.badRequest("invalid_" + field, field + " 不得超过 " + max + " 字符");
        return s.isEmpty() ? null : s;
    }

    /** 标签归一化：trim、去空、去重、Unicode 升序。存储有序可避免同组标签产生多种文件形态。 */
    @SuppressWarnings("unchecked")
    private List<String> normalizeTags(Object v) {
        if (v == null) return new ArrayList<>();
        if (!(v instanceof List<?> list)) throw HttpError.badRequest("invalid_tags", "tags 必须是数组");
        if (list.size() > 20) throw HttpError.badRequest("invalid_tags", "tags 最多 20 个");
        return list.stream()
                .filter(Objects::nonNull)
                .map(o -> String.valueOf(o).trim())
                .filter(s -> !s.isEmpty())
                .peek(s -> {
                    if (s.length() > 24) throw HttpError.badRequest("invalid_tags", "单个标签不得超过 24 字符：" + s);
                    if (s.contains("/")) throw HttpError.badRequest("invalid_tags", "标签不得包含 /（那是学科的层级分隔符）：" + s);
                })
                .distinct().sorted().collect(Collectors.toCollection(ArrayList::new));
    }

    // ================= 查询 =================

    /** 筛选条件容器。字段为 null 表示该维度不过滤。 */
    public static final class Query {
        public String keyword;          // 匹配 title + content，子串，忽略大小写
        public Set<String> tags;        // AND 语义：须全部命中
        public Set<String> statuses;
        public String subject;          // 前缀匹配，"数学" 命中 "数学/线性代数"
        public Boolean pinned;
        public LocalDate dueFrom, dueTo;
        public String sort = "updatedAt";   // updatedAt / createdAt / title / dueDate
        public boolean ascending = false;
        public int page = 1, size = 20;
    }

    public static final class Page<T> {
        public final List<T> items;
        public final int total, page, size, totalPages;
        Page(List<T> items, int total, int page, int size) {
            this.items = items; this.total = total; this.page = page; this.size = size;
            this.totalPages = size <= 0 ? 0 : (int) Math.ceil((double) total / size);
        }
    }

    public Page<Record> query(Category c, Query q) {
        List<Record> filtered = store.all(c).stream()
                .filter(r -> matches(r, q))
                .sorted(comparator(q))
                .toList();

        int total = filtered.size();
        int from = Math.min((q.page - 1) * q.size, total);
        int to   = Math.min(from + q.size, total);
        return new Page<>(filtered.subList(from, to), total, q.page, q.size);
    }

    private boolean matches(Record r, Query q) {
        if (q.keyword != null && !q.keyword.isBlank()) {
            String k = q.keyword.toLowerCase(Locale.ROOT);
            boolean hit = r.title().toLowerCase(Locale.ROOT).contains(k)
                       || (r.content() != null && r.content().toLowerCase(Locale.ROOT).contains(k));
            if (!hit) return false;
        }
        if (q.tags != null && !q.tags.isEmpty() && !new HashSet<>(r.tags()).containsAll(q.tags)) return false;
        if (q.statuses != null && !q.statuses.isEmpty() && !q.statuses.contains(r.status())) return false;
        if (q.subject != null && !q.subject.isBlank()) {
            String s = r.subject();
            if (s == null) return false;
            // 前缀匹配 + 层级边界：subject="数学" 命中 "数学" 和 "数学/线性代数"，但不命中 "数学史"
            if (!s.equals(q.subject) && !s.startsWith(q.subject + "/")) return false;
        }
        if (q.pinned != null && r.pinned() != q.pinned) return false;
        if ((q.dueFrom != null || q.dueTo != null) && c_isTodo(r)) {
            if (r.dueDate() == null) return false;   // 有日期过滤时，无日期的不出现
            LocalDate d = LocalDate.parse(r.dueDate());
            if (q.dueFrom != null && d.isBefore(q.dueFrom)) return false;
            if (q.dueTo   != null && d.isAfter(q.dueTo))    return false;
        }
        return true;
    }

    private boolean c_isTodo(Record r) { return Category.TODO.wire().equals(r.type()); }

    /** 排序：pinned 优先，再按选定键。null 值一律排末尾。 */
    private Comparator<Record> comparator(Query q) {
        Comparator<Record> byPin = Comparator.comparing((Record r) -> !r.pinned());
        Comparator<Record> byKey = switch (q.sort) {
            case "createdAt" -> Comparator.comparing(Record::createdAt, nullsLast());
            case "title"     -> Comparator.comparing(Record::title, nullsLast());
            case "dueDate"   -> Comparator.comparing(Record::dueDate, nullsLast());
            default          -> Comparator.comparing(Record::updatedAt, nullsLast());
        };
        Comparator<Record> c = byPin.thenComparing(q.ascending ? byKey : byKey.reversed());
        return c.thenComparing(Record::id);   // 末尾用 id 兜底，保证排序稳定（分页不抖动）
    }

    private static <U> Comparator<U> nullsLast() {
        return Comparator.nullsLast(Comparator.naturalOrder());
    }
```

> **`comparator` 末尾必须用 `id` 兜底**。若两条记录的 `updatedAt` 完全相同（批量导入时很常见），排序结果在不同 JVM 运行间可能不同，导致**翻页时同一条记录出现在第 1 页和第 2 页**。加 `id` 作为最终决胜键可保证全序稳定。这是分页功能里最隐蔽的 bug。

```java
package com.pouch.service;

import com.pouch.model.Category;
import com.pouch.model.Record;
import com.pouch.store.JsonStore;

import java.util.*;

public class StatsService {

    private final JsonStore store;
    public StatsService(JsonStore store) { this.store = store; }

    /**
     * 总览。返回四类各自的计数与状态分布，以及 todo 的完成率。
     * 前端饼图只取 todoCompletion，但四类分布都返回——
     * 将来想加"问题解决率"环，改前端一行即可（ADR-004）。
     */
    public Map<String, Object> overview() {
        Map<String, Object> out = new LinkedHashMap<>();
        Map<String, Object> counts = new LinkedHashMap<>();
        int grandTotal = 0;

        for (Category c : Category.values()) {
            List<Record> all = store.all(c);
            counts.put(c.wire(), all.size());
            grandTotal += all.size();

            Map<String, Integer> byStatus = new LinkedHashMap<>();
            for (String s : c.allowedStatuses()) byStatus.put(s, 0);   // 预置，保证 0 值也出现
            for (Record r : all) byStatus.merge(r.status(), 1, Integer::sum);
            out.put(c.wire() + "Status", byStatus);
        }

        out.put("counts", counts);
        out.put("total", grandTotal);

        // 饼图口径：done / open，cancelled 不计入（01 §1.4.1）
        Map<String, Integer> todoStatus = asIntMap(out.get("todoStatus"));
        int done = todoStatus.getOrDefault("done", 0);
        int open = todoStatus.getOrDefault("open", 0);
        int cancelled = todoStatus.getOrDefault("cancelled", 0);

        Map<String, Object> completion = new LinkedHashMap<>();
        completion.put("done", done);
        completion.put("open", open);
        completion.put("denominator", done + open);
        // 无待办时返回 null 而非 0——前端显示「暂无待办」而不是 0% 空环
        completion.put("rate", (done + open) == 0 ? null : (double) done / (done + open));

        out.put("todoCompletion", completion);
        out.put("todoCancelled", cancelled);
        return out;
    }

    @SuppressWarnings("unchecked")
    private Map<String, Integer> asIntMap(Object o) { return (Map<String, Integer>) o; }

    /** 全部已用标签及计数，按计数降序，供筛选器与自动补全。 */
    public List<Map<String, Object>> tags() {
        Map<String, Integer> counter = new TreeMap<>();
        for (Category c : Category.values()) {
            for (Record r : store.all(c)) for (String t : r.tags()) counter.merge(t, 1, Integer::sum);
        }
        return counter.entrySet().stream()
                .sorted(Map.Entry.<String, Integer>comparingByValue().reversed()
                        .thenComparing(Map.Entry.comparingByKey()))
                .map(e -> Map.<String, Object>of("tag", e.getKey(), "count", e.getValue()))
                .toList();
    }

    /**
     * 学科树。把 "数学/线性代数" 拆成分层结构，供前端做分组下拉。
     * 每个节点带自身记录数与子树总数。
     */
    public List<Map<String, Object>> subjects() {
        Map<String, Integer> flat = new TreeMap<>();
        for (Record r : store.all(Category.KNOWLEDGE)) {
            if (r.subject() != null) flat.merge(r.subject(), 1, Integer::sum);
        }

        // 构建嵌套树
        Map<String, Object> root = new TreeMap<>();
        for (var e : flat.entrySet()) {
            String[] parts = e.getKey().split("/");
            @SuppressWarnings("unchecked")
            Map<String, Object> node = (Map<String, Object>) root;
            for (String p : parts) {
                @SuppressWarnings("unchecked")
                Map<String, Object> children =
                        (Map<String, Object>) node.computeIfAbsent(p, k -> new TreeMap<String, Object>());
                node = children;
            }
            node.put("__count", e.getValue());
        }
        return flatten(root, null);
    }

    /** 树 → 扁平列表（带 path 与 depth），前端按需分组渲染。 */
    private List<Map<String, Object>> flatten(Map<String, Object> node, String parentPath) {
        List<Map<String, Object>> out = new ArrayList<>();
        int depth = parentPath == null ? 0 : parentPath.split("/").length;
        for (var e : node.entrySet()) {
            if ("__count".equals(e.getKey())) continue;
            @SuppressWarnings("unchecked")
            Map<String, Object> child = (Map<String, Object>) e.getValue();
            String path = parentPath == null ? e.getKey() : parentPath + "/" + e.getKey();

            int own = child.containsKey("__count") ? (int) child.get("__count") : 0;
            List<Map<String, Object>> sub = flatten(child, path);
            int subtree = own + sub.stream().mapToInt(m -> (int) m.get("count")).sum();

            Map<String, Object> entry = new LinkedHashMap<>();
            entry.put("path", path);
            entry.put("name", e.getKey());
            entry.put("depth", depth);
            entry.put("ownCount", own);
            entry.put("count", subtree);
            out.add(entry);
            out.addAll(sub);
        }
        return out;
    }
}
```

> **`flatten` 的实现有缺陷**：它先递归 `sub` 再用 `sub` 求和，逻辑正确，但**输出顺序是"父 → 子的整棵子树 → 下一个兄弟"**（深度优先），而前端下拉框通常需要这个顺序，所以没问题。但要留意 `count`（子树总数）的计算依赖递归返回值的顺序——如果将来改成先收集后计算，必须同步调整。此处保留深度优先实现并注明。
>
> 另：`(int) child.get("__count")` 在 `__count` 不存在时会 NPE，代码中已用 `containsKey` 保护，改动时不要删掉这个保护。

```java
package com.pouch.service;

import com.pouch.HttpError;
import com.pouch.model.WishItem;
import com.pouch.store.JsonStore;

import java.util.*;

public class WishlistService {

    private static final long MAX_AMOUNT_CENTS = 999_999_999_99L;   // ≈10 亿元，见 01 §1.5.1

    private final JsonStore store;
    public WishlistService(JsonStore store) { this.store = store; }

        for (WishItem w : items) {
            total += w.amountCents();
            if (w.purchased()) spent += w.amountCents();
        }
        Map<String, Long> m = new LinkedHashMap<>();
        m.put("totalWishCents", total);
        m.put("spentCents", spent);
        m.put("remainingCents", total - spent);
        m.put("itemCount", (long) items.size());
        m.put("purchasedCount", items.stream().filter(WishItem::purchased).count());
        return m;
    }

        WishItem w = new WishItem();
        w.setId(UUID.randomUUID().toString());
        String now = JsonStore.nowIso();
        w.setCreatedAt(now);
        w.setUpdatedAt(now);
        w.setName(requireName(in.get("name")));
        w.setAmountCents(requireAmount(in.get("amountCents")));
        w.setNote(requireNote(in.get("note")));
        w.setPurchased(false);            // 新建时强制为未购，忽略传入值
        // sortIndex 取现有最大值 +1
        w.setSortIndex(store.allWishes().stream().mapToInt(WishItem::sortIndex).max().orElse(-1) + 1);

        store.insertWish(w);
        return w;

    public WishItem update(String id, Map<String, Object> patch) {
        WishItem existing = store.findWish(id)
                .orElseThrow(() -> HttpError.notFound("wish_not_found", "找不到心愿条目 " + id));

        boolean ok = store.updateWish(id, w -> {
            if (patch.containsKey("name"))        w.setName(requireName(patch.get("name")));
            if (patch.containsKey("amountCents")) w.setAmountCents(requireAmount(patch.get("amountCents")));
            if (patch.containsKey("note"))        w.setNote(requireNote(patch.get("note")));
            if (patch.containsKey("sortIndex"))   w.setSortIndex(requireSortIndex(patch.get("sortIndex")));

                    w.setPurchased(p);
                    w.setPurchasedAt(p ? JsonStore.nowIso() : null);   // 转假时清空
                }

        String s = String.valueOf(v).trim();
        if (s.isEmpty())      throw HttpError.badRequest("invalid_wish_name", "name 不能为空");
        if (s.length() > 120) throw HttpError.badRequest("invalid_wish_name", "name 不得超过 120 字符");

    }

    /** 金额校验：必须是非负整数。拒绝浮点，避免前端传 2388.00 造成精度歧义。 */
    private long requireAmount(Object v) {
        if (v == null) throw HttpError.badRequest("invalid_amount", "amountCents 为必填项");
        long cents;
        if (v instanceof Number n) {
            double d = n.doubleValue();
            if (d != Math.floor(d)) {
                throw HttpError.badRequest("invalid_amount",
                        "amountCents 必须是整数（单位为分）。若要表示 " + d + " 分，请传整数。");
            }
            cents = n.longValue();
        } else {
            try { cents = Long.parseLong(String.valueOf(v).trim()); }
            catch (NumberFormatException e) {
                throw HttpError.badRequest("invalid_amount", "amountCents 必须是整数：" + v);
            }
        }
        if (cents < 0) throw HttpError.badRequest("invalid_amount", "amountCents 不得为负数");
        if (cents > MAX_AMOUNT_CENTS) {
            throw HttpError.badRequest("invalid_amount",
                    "amountCents 超出上限 " + MAX_AMOUNT_CENTS + "（约 10 亿元）");
        }
        return cents;
    }

    private String requireNote(Object v) {
        if (v == null) return "";
        String s = String.valueOf(v).trim();
        if (s.length() > 500) throw HttpError.badRequest("invalid_wish_note", "note 不得超过 500 字符");
        return s;
    }

    private int requireSortIndex(Object v) {
        if (v == null) throw HttpError.badRequest("invalid_sort_index", "sortIndex 为必填项");
        int i;
        try { i = Integer.parseInt(String.valueOf(v).trim()); }
        catch (NumberFormatException e) { throw HttpError.badRequest("invalid_sort_index", "sortIndex 必须是整数"); }
        if (i < 0 || i > 1_000_000) throw HttpError.badRequest("invalid_sort_index", "sortIndex 须在 0~1000000");
        return i;
    }
```

## 2.6 Handler 层

Handler 只做 HTTP 语义转换。**所有 Handler 共享同一个异常处理包装**，避免每处都写 try-catch。

```java
package com.pouch.handler;

import com.pouch.*;
import com.google.gson.JsonObject;
import com.sun.net.httpserver.HttpExchange;

import java.io.IOException;
import java.util.Map;

/** Handler 基类：统一异常捕获与错误信封输出。 */
public abstract class BaseHandler {

    protected abstract void doHandle(HttpExchange ex, Map<String, String> path) throws IOException;

    public final void handle(HttpExchange ex, Map<String, String> path) throws IOException {
        try {
            doHandle(ex, path);
        } catch (HttpError e) {
            Respond.error(ex, e.status, e.code, e.getMessage());
        } catch (com.pouch.store.StoreException e) {
            System.err.println("[ERROR] 存储层异常：" + e.getMessage());
            e.printStackTrace();
            Respond.error(ex, 500, "storage_error", "数据读写失败，详见服务端日志");
        } catch (Exception e) {
            System.err.println("[ERROR] 未预期异常：" + e);
            e.printStackTrace();
            Respond.error(ex, 500, "internal_error", "服务器内部错误");
        }
    }

    // ---- 参数解析辅助 ----

    protected JsonObject body(HttpExchange ex) throws IOException {
        return Requests.readJsonBody(ex);
    }

    protected Map<String, String> query(HttpExchange ex) { return Requests.queryParams(ex); }

    /** 逗号分隔的多值参数：?tags=a,b → Set{a,b}；缺失或空返回 null（表示不过滤）。 */
    protected java.util.Set<String> csvSet(String raw) {
        if (raw == null || raw.isBlank()) return null;
        return java.util.Arrays.stream(raw.split(","))
                .map(String::trim).filter(s -> !s.isEmpty())
                .collect(java.util.stream.Collectors.toCollection(java.util.LinkedHashSet::new));
    }

    protected int intOr(String raw, int dflt, int min, int max) {
        if (raw == null || raw.isBlank()) return dflt;
        try { return Math.clamp(Integer.parseInt(raw.trim()), min, max); }
        catch (NumberFormatException e) { return dflt; }
    }

    /** 查询参数校验采取宽容策略：非法值回退默认，不报错（01 §1.9）。 */
    protected String oneOf(String raw, String dflt, String... allowed) {
        if (raw == null) return dflt;
        for (String a : allowed) if (a.equals(raw)) return a;
        return dflt;
    }
}
```

> **`Math.clamp` 是 Java 21 新增方法**（JDK 21 起可用）。若编译报找不到符号，说明实际 JDK 版本低于 21，改用 `Math.max(min, Math.min(max, v))`。

```java
    private static final Gson GSON = new Gson();
    private final RecordService service;

    public RecordHandler(RecordService service) { this.service = service; }

    @Override
    protected void doHandle(HttpExchange ex, Map<String, String> path) throws IOException {
        String method = ex.getRequestMethod().toUpperCase(Locale.ROOT);
        Map<String, String> q = query(ex);

        // ---- 集合：GET /api/records?type=todo&... ----
        if (path.get("id") == null) {
            switch (method) {
                case "GET" -> {
                    Category c = categoryOf(q.get("type"));
                    RecordService.Page<Record> page = service.query(c, buildQuery(q));
                    Respond.json(ex, 200, Map.of(
                            "items", page.items,
                            "pagination", Map.of(
                                    "total", page.total, "page", page.page,
                                    "size", page.size, "totalPages", page.totalPages)));
                }
                case "POST" -> {
                    Category c = categoryOf(q.get("type"));
                    Record r = service.create(c, GSON.fromJson(body(ex), Map.class));
                    Respond.json(ex, 201, r);
                }
                default -> throw new HttpError(405, "method_not_allowed", method + " 不被 /api/records 支持");
            }
            return;
        }

        // ---- 单条：/api/records/{id} ----
        String id = path.get("id");
        Category c = resolveCategoryForId(id, q.get("type"));   // 见下方说明

        switch (method) {
            case "GET"    -> Respond.json(ex, 200, service.get(c, id));
            case "PATCH"  -> Respond.json(ex, 200, service.update(c, id, GSON.fromJson(body(ex), Map.class)));
            case "DELETE" -> { service.delete(c, id); Respond.noContent(ex); }
            default -> throw new HttpError(405, "method_not_allowed", method + " 不被 /api/records/{id} 支持");
        }
    }

    private Category categoryOf(String raw) {
        if (raw == null || raw.isBlank()) {
            throw HttpError.badRequest("invalid_type",
                    "必须指定 type 参数，可选值：inspiration / question / knowledge / todo");
        }
        try { return Category.fromWire(raw); }
        catch (IllegalArgumentException e) {
            throw HttpError.badRequest("invalid_type",
                    "type 非法：" + raw + "（可选：inspiration / question / knowledge / todo）");
        }
    }

    /**
     * 单条操作的类别解析：
     * - 若带了 ?type=，直接用（快，且允许精确控制）
     * - 否则按枚举序遍历四个文件查找 id（前端从详情页调用时通常不知道类别）
     *
     * 遍历的成本是 4 次 HashMap 查找，可忽略。
     */
    private Category resolveCategoryForId(String id, String typeParam) {
        if (typeParam != null && !typeParam.isBlank()) return categoryOf(typeParam);
        for (Category c : Category.values()) {
            if (service.exists(c, id)) return c;
        }
        throw HttpError.notFound("record_not_found", "找不到记录 " + id);
    }

    private RecordService.Query buildQuery(Map<String, String> q) {
        RecordService.Query query = new RecordService.Query();
        query.keyword  = q.get("q");
        query.tags     = csvSet(q.get("tags"));
        query.statuses = csvSet(q.get("status"));
        query.subject  = q.get("subject");
        if (q.get("pinned") != null) query.pinned = Boolean.parseBoolean(q.get("pinned"));
        query.dueFrom  = parseDate(q.get("dueFrom"), "dueFrom");
        query.dueTo    = parseDate(q.get("dueTo"),   "dueTo");
        query.sort     = oneOf(q.get("sort"), "updatedAt", "updatedAt", "createdAt", "title", "dueDate");
        query.ascending= "asc".equalsIgnoreCase(q.get("order"));
        query.page     = intOr(q.get("page"), 1,   1, Integer.MAX_VALUE);
        query.size     = intOr(q.get("size"), 20,  1, 200);
        return query;
    }

    private java.time.LocalDate parseDate(String raw, String field) {
        if (raw == null || raw.isBlank()) return null;
        try { return java.time.LocalDate.parse(raw.trim()); }
        catch (java.time.format.DateTimeParseException e) {
            throw HttpError.badRequest("invalid_" + field, field + " 须为 yyyy-MM-dd 格式：" + raw);
        }
    }
}
```

> **`resolveCategoryForId` 的遍历查找是一个刻意的设计选择**。替代方案是强制前端在所有单条操作上都带 `?type=`，但那样详情页 URL（`detail.html?id=xxx`）就必须同时携带 type，而用户可能从书签、浏览器历史进入，参数容易丢失。4 次 HashMap 查找的代价换来 URL 的健壮性，值得。

`StatsHandler` / `WishlistHandler` / `MetaHandler` 的结构与此相同（解析参数 → 调 Service → `Respond.json`），完整端点行为见 [03-API契约](./03-API契约.md)，实现时按契约逐个补齐即可。笔记相关的三个端点（新增/编辑/删除单条笔记）见 03 §3.4，实现要点：

- 操作在 `RecordService` 内完成，通过 `store.updateRecord` 修改 `notes` 列表，**保证与记录本体在同一文件、同一次原子写**内落盘。
- 追加笔记时同时更新父记录的 `updatedAt`（01 §1.2.1）。
- **不提供整体替换 `notes` 数组的端点**（01 §1.3 的追加式语义）。

## 2.7 静态资源服务

### `StaticHandler.java`

```java
package com.pouch.handler;

import com.pouch.HttpError;
import com.pouch.Respond;
import com.sun.net.httpserver.HttpExchange;

import java.io.IOException;
import java.io.OutputStream;
import java.nio.file.*;
import java.util.Map;

public class StaticHandler {

    /** 扩展名 → Content-Type。未列出的按 application/octet-stream。 */
    private static final Map<String, String> MIME = Map.ofEntries(
            Map.entry("html", "text/html; charset=utf-8"),
            Map.entry("css",  "text/css; charset=utf-8"),
            Map.entry("js",   "application/javascript; charset=utf-8"),
            Map.entry("json", "application/json; charset=utf-8"),
            Map.entry("svg",  "image/svg+xml"),
            Map.entry("png",  "image/png"),
            Map.entry("jpg",  "image/jpeg"),
            Map.entry("jpeg", "image/jpeg"),
            Map.entry("gif",  "image/gif"),
            Map.entry("webp", "image/webp"),
            Map.entry("ico",  "image/x-icon"),
            Map.entry("woff2","font/woff2"),
            Map.entry("map",  "application/json; charset=utf-8"));

    private final Path webRoot;

    public StaticHandler(Path webRoot) {
        this.webRoot = webRoot.toAbsolutePath().normalize();
    }

    public void serve(HttpExchange ex) throws IOException {
        String rawPath = ex.getRequestURI().getPath();
        if ("/".equals(rawPath) || rawPath.isEmpty()) rawPath = "/index.html";

        // SPA 风格的深链回退：/list、/detail 这类无扩展名路径映射到对应 .html
        if (!rawPath.contains(".")) {
            String cand = rawPath + ".html";
            if (Files.exists(webRoot.resolve(cand.substring(1)))) rawPath = cand;
        }

        Path target = webRoot.resolve(rawPath.substring(1)).normalize();

        // ★ 路径穿越防护：normalize 后必须仍在 webRoot 之内
        if (!target.startsWith(webRoot)) {
            Respond.error(ex, 403, "forbidden", "非法路径");
            return;
        }
        // ★ 禁止访问隐藏文件/目录（.backup、.git 等）
        for (Path seg : webRoot.relativize(target)) {
            if (seg.toString().startsWith(".")) {
                Respond.error(ex, 403, "forbidden", "非法路径");
                return;
            }
        }

        if (!Files.exists(target) || Files.isDirectory(target)) {
            // 目录或不存在 → 回退到 index.html（让前端路由处理），并给 404 语义
            Path fallback = webRoot.resolve("index.html");
            if (!Files.exists(fallback)) { Respond.error(ex, 404, "not_found", "资源不存在"); return; }
            target = fallback;
        }

        String name = target.getFileName().toString();
        String ext = name.contains(".") ? name.substring(name.lastIndexOf('.') + 1).toLowerCase() : "";
        ex.getResponseHeaders().set("Content-Type", MIME.getOrDefault(ext, "application/octet-stream"));
        // HTML 不缓存（开发期改完刷新即生效）；静态资源带版本号可长缓存
        ex.getResponseHeaders().set("Cache-Control",
                ext.equals("html") ? "no-store" : "public, max-age=3600");

        byte[] bytes = Files.readAllBytes(target);
        if ("HEAD".equalsIgnoreCase(ex.getRequestMethod())) {
            ex.sendResponseHeaders(200, -1);
            ex.close();
            return;
        }
        ex.sendResponseHeaders(200, bytes.length);
        try (OutputStream os = ex.getResponseBody()) { os.write(bytes); }
    }
}
```

### 2.7.1 路径穿越防护（必须理解）

`webRoot.resolve("../../data/todos.json")` 会解析到数据目录之外。若不做检查，攻击者（或误操作）可通过 `GET /../../data/todos.json` 读到数据文件。虽然本项目只监听 `127.0.0.1`、单用户，风险极低，但**这是安全习惯问题，不是威胁模型问题**——写代码时应当默认做对。

两道防线：

1. **`normalize()` 后 `startsWith(webRoot)`**：把 `..` 解析掉再比对前缀。这是主防线。
2. **拒绝任何以 `.` 开头的路径段**：即使穿越失败，也挡掉 `.backup/`、`.git/` 这类隐藏目录。

> 注意 `webRoot` 本身必须已经 `toAbsolutePath().normalize()`，否则 `startsWith` 比对的是相对路径，防护失效。构造函数里已经做了。

## 2.8 服务入口

### `PouchServer.java`

```java
package com.pouch;

import com.pouch.handler.*;
import com.pouch.model.Category;
import com.pouch.service.*;
import com.pouch.store.JsonStore;
import com.sun.net.httpserver.HttpServer;

import java.io.IOException;
import java.net.InetAddress;
import java.net.InetSocketAddress;
import java.nio.file.*;
import java.util.concurrent.Executors;

public class PouchServer {

    public static void main(String[] args) throws Exception {
        Args a = Args.parse(args);

        if (a.help) { printUsage(); return; }

        Path dataDir = Path.of(a.data).toAbsolutePath().normalize();
        Path webDir  = Path.of(a.web).toAbsolutePath().normalize();

        System.out.println("Pouch 学习看板");
        System.out.println("  数据目录 : " + dataDir);
        System.out.println("  静态目录 : " + webDir);

        if (!Files.isDirectory(webDir)) {
            System.err.println("[FATAL] 静态目录不存在：" + webDir);
            System.err.println("        请用 --web=<路径> 指定，或确认目录结构完整。");
            System.exit(1);
        }

        // ---- 加载数据（损坏文件会走恢复流程，不致命） ----
        JsonStore store = new JsonStore(dataDir);
        try {
            store.load();
        } catch (Exception e) {
            System.err.println("[FATAL] 数据加载失败：" + e.getMessage());
            System.exit(1);
        }

        RecordService   records  = new RecordService(store);
        StatsService    stats    = new StatsService(store);
        WishlistService wishes   = new WishlistService(store);

        printDataSummary(store, wishes);

        // ---- 组装路由 ----
        StaticHandler staticHandler = new StaticHandler(webDir);
        Router router = new Router(staticHandler);

        RecordHandler   rh = new RecordHandler(records);
        WishlistHandler wh = new WishlistHandler(wishes);
        StatsHandler    sh = new StatsHandler(stats, records, wishes);
        MetaHandler     mh = new MetaHandler(stats);

        // 记录
        router.register("GET",    "/api/records",            rh::handle)
              .register("POST",   "/api/records",            rh::handle)
              .register("GET",    "/api/records/{id}",       rh::handle)
              .register("PATCH",  "/api/records/{id}",       rh::handle)
              .register("DELETE", "/api/records/{id}",       rh::handle)
              // 笔记（03 §3.3）
              .register("POST",   "/api/records/{id}/notes",          rh::handle)
              .register("PATCH",  "/api/records/{id}/notes/{noteId}", rh::handle)
              .register("DELETE", "/api/records/{id}/notes/{noteId}", rh::handle);

        // 心愿单
        router.register("GET",    "/api/wishlist",       wh::handle)
              .register("POST",   "/api/wishlist",       wh::handle)
              .register("PATCH",  "/api/wishlist/{id}",  wh::handle)
              .register("DELETE", "/api/wishlist/{id}",  wh::handle);

        // 统计
        router.register("GET",    "/api/stats/overview", sh::handle)
              .register("GET",    "/api/stats/random",   sh::handle);

        // 元数据
        router.register("GET",    "/api/meta/tags",     mh::handle)
              .register("GET",    "/api/meta/subjects", mh::handle)
              .register("GET",    "/api/meta/categories", mh::handle)
              .register("GET",    "/api/health",        mh::handle);

        // ---- 启动 ----
        HttpServer server;
        try {
            // ★ 只绑定回环地址，不对外暴露
            server = HttpServer.create(new InetSocketAddress(InetAddress.getLoopbackAddress(), a.port), 0);
        } catch (IOException e) {
            System.err.println("[FATAL] 无法绑定端口 " + a.port + "：" + e.getMessage());
            System.err.println("        端口可能已被占用。用 --port=<其他端口> 换一个，");
            System.err.println("        或执行 netstat -ano | findstr :" + a.port + " 查看占用进程。");
            System.exit(1);
            return;
        }

        server.createContext("/", router::handle);
        // 固定 8 线程池：单用户足够，且避免无界线程耗尽资源
        server.setExecutor(Executors.newFixedThreadPool(8));
        server.start();

        System.out.println();
        System.out.println("  ✓ 已启动 → http://127.0.0.1:" + a.port);
        System.out.println("  按 Ctrl+C 停止");
        System.out.println();

        // ---- 优雅关闭：确保进行中的写入完成 ----
        Runtime.getRuntime().addShutdownHook(new Thread(() -> {
            System.out.println("\n正在停止…");
            server.stop(2);   // 最多等 2 秒让进行中的请求完成
            System.out.println("已停止。");
        }));
    }

    private static void printDataSummary(JsonStore store, WishlistService wishes) {
        StringBuilder sb = new StringBuilder("  已载入   : ");
        int total = 0;
        for (Category c : Category.values()) {
            int n = store.all(c).size();
            total += n;
            sb.append(c.label()).append(' ').append(n).append("  ");
        }
        var sum = wishes.summarize(wishes.list());
        System.out.println(sb);
        System.out.printf("             共 %d 条记录；心愿单 %d 项（总计 %.2f 元，已花 %.2f 元，还差 %.2f 元）%n",
                total, sum.get("itemCount"),
                sum.get("totalWishCents") / 100.0,
                sum.get("spentCents") / 100.0,
                sum.get("remainingCents") / 100.0);
    }

    private static void printUsage() {
        System.out.println("""
        Pouch 学习看板 · 本地服务器

        用法：java -cp <classpath> com.pouch.PouchServer [选项]

        选项：
          --port=<n>      监听端口，默认 8787
          --data=<path>   数据目录，默认 ./data
          --web=<path>    静态资源目录，默认 ./web
          -h, --help      显示本帮助

        示例：
          java -cp "server/out;server/lib/*" com.pouch.PouchServer --port=9000
        """);
    }

    /** 极简参数解析。 */
    static final class Args {
        int port = 8787;
        String data = "data";
        String web = "web";
        boolean help = false;

        static Args parse(String[] argv) {
            Args a = new Args();
            for (String s : argv) {
                if (s.equals("-h") || s.equals("--help")) { a.help = true; continue; }
                int i = s.indexOf('=');
                if (i < 0 || !s.startsWith("--")) {
                    System.err.println("[WARN] 忽略无法识别的参数：" + s);
                    continue;
                }
                String k = s.substring(2, i), v = s.substring(i + 1);
                switch (k) {
                    case "port" -> {
                        try { a.port = Integer.parseInt(v.trim()); }
                        catch (NumberFormatException e) {
                            System.err.println("[FATAL] --port 必须是整数：" + v); System.exit(1);
                        }
                        if (a.port < 1 || a.port > 65535) {
                            System.err.println("[FATAL] --port 须在 1~65535：" + a.port); System.exit(1);
                        }
                    }
                    case "data" -> a.data = v;
                    case "web"  -> a.web  = v;
                    default -> System.err.println("[WARN] 忽略未知选项：--" + k);
                }
            }
            return a;
        }
    }
}
```

**几个实现要点**：

1. **`InetAddress.getLoopbackAddress()` 而非 `new InetSocketAddress(port)`**。后者绑定 `0.0.0.0`，会让局域网内任何设备都能访问你的学习记录和心愿单。前者只绑 `127.0.0.1`。这不是可选的加固，是默认该有的行为。
2. **`server.stop(2)` 给 2 秒宽限**。若关闭时正有写入在进行，`JsonStore` 的写锁能保证写盘完成或回滚；宽限期避免请求被硬切断。
3. **`Executors.newFixedThreadPool(8)`**：`HttpServer` 默认执行器为 `null`（单线程串行处理），会让静态资源请求阻塞 API 请求。必须显式设置线程池。

```powershell
$ErrorActionPreference = 'Stop'
$root = Split-Path -Parent $PSScriptRoot     # 仓库根（server/ 的上一级）
$src  = Join-Path $PSScriptRoot 'src'
$out  = Join-Path $PSScriptRoot 'out'

Write-Host "→ 清理输出目录 $out"
if (Test-Path $out) { Remove-Item -Recurse -Force $out }

# 检查依赖
$jars = Get-ChildItem -Path $lib -Filter '*.jar' -ErrorAction SilentlyContinue
if (-not $jars) {

}

# 收集源文件（用文件列表而非通配，避免 javac 参数长度限制）
$sources = Get-ChildItem -Path $src -Recurse -Filter '*.java' | ForEach-Object { $_.FullName }
$listFile = Join-Path $out 'sources.txt'
$sources | Set-Content -Path $listFile -Encoding utf8

Write-Host "→ 编译 $($sources.Count) 个源文件"
$cp = "$lib\*"
& javac -encoding UTF-8 -d $out -cp $cp "@$listFile"
if ($LASTEXITCODE -ne 0) { Write-Error "编译失败"; exit $LASTEXITCODE }

Remove-Item $listFile -Force
Write-Host "✓ 编译完成 → $out"
```

```powershell
# 编译（若需要）并启动 Pouch 服务器。
param(
    [int]$Port = 8787,
    [string]$Data = '',
    [string]$Web = ''
)
$ErrorActionPreference = 'Stop'
$root = Split-Path -Parent $PSScriptRoot
$out  = Join-Path $PSScriptRoot 'out'
$lib  = Join-Path $PSScriptRoot 'lib'

# 源文件比 class 新则重新编译
$needBuild = -not (Test-Path $out)
if (-not $needBuild) {
    $newestSrc   = (Get-ChildItem (Join-Path $PSScriptRoot 'src') -Recurse -Filter '*.java' |
                    Sort-Object LastWriteTime -Descending | Select-Object -First 1).LastWriteTime
    $newestClass = (Get-ChildItem $out -Recurse -Filter '*.class' |
                    Sort-Object LastWriteTime -Descending | Select-Object -First 1).LastWriteTime
    if ($newestSrc -gt $newestClass) { $needBuild = $true }
}
if ($needBuild) { & (Join-Path $PSScriptRoot 'build.ps1'); if ($LASTEXITCODE -ne 0) { exit 1 } }

# 默认路径：数据与静态资源都在仓库根下
if (-not $Data) { $Data = Join-Path $root 'data' }
if (-not $Web)  { $Web  = Join-Path $root 'web'  }

# Windows classpath 分隔符是分号；lib\* 展开所有 jar
$cp = "$out;$lib\*"
& java -Dfile.encoding=UTF-8 -cp $cp com.pouch.PouchServer --port=$Port --data="$Data" --web="$Web"
```

## 2.10 实现顺序建议

按此顺序写，每步都能独立验证，不会积累一堆未测代码：

| 步骤 | 内容 | 验证方式 |
|---|---|---|
| 1 | `Category` + 模型类（4 个） | 能编译通过 |
| 2 | `JsonStore` 的 `load` + 空文件创建 | 启动后 `data/` 出现 5 个空结构文件 |
| 3 | `PouchServer` + `StaticHandler` + `Router` | 浏览器访问 `http://127.0.0.1:8787` 能看到 index.html |
| 4 | `JsonStore` 的 `insert/update/delete` + 原子写 | 手动造一条数据，确认文件内容与 `.backup/` 生成 |
| 5 | `RecordService` 的 create/update + 校验 | 用 `curl` 或 PowerShell `Invoke-RestMethod` 打 POST，验证 400 错误码 |
| 6 | `RecordHandler` 全套端点 | 完整 CRUD 走通 |
| 7 | `StatsService` + `StatsHandler` | `/api/stats/overview` 返回正确计数 |
| 8 | `WishlistService` + Handler | 心愿单 CRUD 与三项汇总 |
| 9 | `MetaHandler` | 标签与学科列表 |
| 10 | 随机抽取端点 | `/api/stats/random` 多次调用返回不同结果 |

**每步的验证命令示例**（PowerShell）：

```powershell
# 建一条待办
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/records?type=todo' -Method Post `
  -ContentType 'application/json; charset=utf-8' `
  -Body (@{ title='测试待办'; content='正文'; tags=@('测试'); dueDate='2026-10-10' } | ConvertTo-Json)

# 查列表
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/records?type=todo&page=1&size=20'

# 看统计
Invoke-RestMethod -Uri 'http://127.0.0.1:8787/api/stats/overview' | ConvertTo-Json -Depth 5
```

> **`Invoke-RestMethod` 发中文的坑**：PowerShell 5.1 的 `-Body` 传字符串时按 ASCII 编码，中文会变问号。解决：`-Body ([System.Text.Encoding]::UTF8.GetBytes($jsonString))`，或把 JSON 写入 UTF-8 文件后用 `-InFile`。这一点在 05 §5.7 的 FAQ 里有详细说明。
