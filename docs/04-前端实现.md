## 4.1 页面与路由

三个独立 HTML 页面，由 Java 后端的 `StaticHandler` 托管。**无前端路由框架**，页面间跳转用普通 `<a href>` 与 `location.href`。

| 文件 | URL | 职责 |
|---|---|---|
| `index.html` | `/` 或 `/index.html` | 首页看板（区块 A~E） |
| `list.html` | `/list.html?type=knowledge` | 分类列表 + 筛选 |
| `detail.html` | `/detail.html?id=<uuid>` | 详情查看 / 编辑 / 笔记 / 标签 |

**URL 参数约定**

| 页面 | 参数 | 说明 |
|---|---|---|
| `list.html` | `type` | 当前类别。缺失时默认 `todo`（最常用的类别） |
| | `subject` | 预选学科（从首页学科入口跳入时用） |
| | `q` | 预选关键词（从首页搜索框跳入时用） |
| | `tag` | 预选单个标签 |
| `detail.html` | `id` | **必填**。记录 UUID |
| | `from` | 来源页 URL，用于"返回"按钮回到原筛选状态。可选 |

> **`detail.html` 只需 `id`，不需要 `type`**——`GET /api/records/{id}` 支持不带 type 的跨类别查找（03 §3.3）。这让详情页链接可以随意分享、收藏，不会因参数缺失而 404。

**`from` 参数的必要性**：用户在列表页筛选出「数学/线性代数 + 学习中」的结果，点进一条详情，看完点返回——若返回到无参数的 `list.html`，筛选条件全丢，需要重新设置。把来源 URL 编码进 `from`，返回时 `history.back()` 优先，`from` 作为兜底（浏览器历史被清空时仍可用）。

```js
// list.html 中生成详情链接
const from = encodeURIComponent(location.pathname + location.search);
a.href = `/detail.html?id=${r.id}&from=${from}`;

// detail.html 中返回
const from = new URLSearchParams(location.search).get('from');
backBtn.onclick = () => {
  if (history.length > 1) history.back();
  else location.href = from ? decodeURIComponent(from) : '/list.html';
};
```

### 4.2.1 对比度校验

关键前景/背景组合的对比度（WCAG 2.1）：

| 组合 | 浅色 | 深色 | 要求 |
|---|---|---|---|
| `--text` / `--bg-surface` | 13.2:1 | 12.8:1 | AA 需 ≥4.5 ✅ |
| `--text-muted` / `--bg-surface` | 6.1:1 | 6.4:1 | AA 需 ≥4.5 ✅ |
| `--text-subtle` / `--bg-surface` | 4.6:1 | 4.5:1 | AA 需 ≥4.5 ✅（临界，仅用于时间戳等非关键信息） |
| `--text-invert` / `--accent` | 5.9:1 | 8.1:1 | AA 需 ≥4.5 ✅ |

**`--text-subtle` 已在临界值**，不得用于正文或任何需要阅读的内容，只用于时间戳、计数徽标这类"看不到也不影响使用"的辅助信息。

## 4.3 API 封装层（`js/api.js`）

**唯一发起 `fetch` 的地方**。页面代码只调用 `api.xxx()`（03 §3.10）。

```js
/* ============================================================
   api.js —— 后端接口封装
   约定（见 03 §3.10）：
     · 所有函数返回 Promise，resolve 已解析的 JSON 对象
     · 非 2xx 一律 reject 一个 ApiError { status, code, message }
     · 页面代码中不得出现 fetch(
   ============================================================ */

/** 结构化错误。页面据此做展示或分支处理。 */
export class ApiError extends Error {
  constructor(status, code, message) {
    super(message || `请求失败（${status}）`);
    this.name = 'ApiError';
    this.status = status;
    this.code = code || 'unknown';
  }
  /** 是否为网络层故障（服务未启动/断连）。与业务错误区分处理，见 §4.9。 */
  get isNetwork() { return this.status === 0; }
}

// ---- 内部工具 ----

const BASE = '';   // 同源，无需前缀。若前后端分离部署改为 'http://127.0.0.1:8787'

/** 构造查询串。自动跳过 null/undefined/空串/空数组。 */
function qs(params) {
  if (!params) return '';
  const sp = new URLSearchParams();
  for (const [k, v] of Object.entries(params)) {
    if (v === null || v === undefined || v === '') continue;
    if (Array.isArray(v)) { if (v.length) sp.set(k, v.join(',')); continue; }
    sp.set(k, String(v));
  }
  const s = sp.toString();
  return s ? `?${s}` : '';
}

/**
 * 统一请求。
 * @param {string} method
 * @param {string} path   已含查询串
 * @param {object} [body] 会被 JSON.stringify；不传则无请求体
 */
async function request(method, path, body) {
  const opts = {
    method,
    headers: { 'Accept': 'application/json' },
    // 关键：不加任何缓存，避免 PATCH 后 GET 到旧数据（后端也发了 no-store）
    cache: 'no-store',
  };
  if (body !== undefined) {
    opts.headers['Content-Type'] = 'application/json; charset=utf-8';
    opts.body = JSON.stringify(body);
  }

  let res;
  try {
    res = await fetch(BASE + path, opts);
  } catch (e) {
    // fetch 只在网络层失败时抛（服务未启动、连接被拒）
    throw new ApiError(0, 'network_error',
      '无法连接到本地服务器。请确认 Pouch 服务已启动（运行 server\\start.ps1）。');
  }

  if (res.status === 204) return null;   // DELETE 记录：无响应体

  // 解析 JSON。响应体本身解析失败时给出可读错误而非 SyntaxError
  let data = null;
  const text = await res.text();
  if (text) {
    try { data = JSON.parse(text); }
    catch { throw new ApiError(res.status, 'bad_response', '服务器返回了非 JSON 内容'); }
  }

  if (!res.ok) {
    const err = data?.error || {};
    throw new ApiError(res.status, err.code, err.message);
  }
  return data;
}

// ---- 导出的 API ----

export const api = {
  // 元数据
  health:     ()            => request('GET', '/api/health'),
  categories: ()            => request('GET', '/api/meta/categories'),
  tags:       ()            => request('GET', '/api/meta/tags'),
  subjects:   ()            => request('GET', '/api/meta/subjects'),

  // 记录
  /**
   * @param {string} type    inspiration|question|knowledge|todo
   * @param {object} filters { q, tags, status, subject, pinned, dueFrom, dueTo, sort, order, page, size }
   */
  listRecords: (type, filters = {}) =>
    request('GET', `/api/records${qs({ type, ...filters })}`),

  /** @param {string} [type] 已知类别时传入，可省去服务端跨文件查找 */
  getRecord:    (id, type) => request('GET', `/api/records/${enc(id)}${qs({ type })}`),
  createRecord: (type, data) => request('POST', `/api/records${qs({ type })}`, data),
  updateRecord: (id, patch, type) =>
    request('PATCH', `/api/records/${enc(id)}${qs({ type })}`, patch),
  deleteRecord: (id, type) => request('DELETE', `/api/records/${enc(id)}${qs({ type })}`),

  // 笔记（返回的都是父记录完整对象，见 03 §3.4）
  addNote:    (id, content) => request('POST',   `/api/records/${enc(id)}/notes`, { content }),
  editNote:   (id, noteId, content) =>
    request('PATCH', `/api/records/${enc(id)}/notes/${enc(noteId)}`, { content }),
  deleteNote: (id, noteId) => request('DELETE', `/api/records/${enc(id)}/notes/${enc(noteId)}`),

  // 心愿单
  wishlist:   ()          => request('GET', '/api/wishlist'),
  addWish:    (data)      => request('POST', '/api/wishlist', data),
  updateWish: (id, patch) => request('PATCH', `/api/wishlist/${enc(id)}`, patch),
  deleteWish: (id)        => request('DELETE', `/api/wishlist/${enc(id)}`),

  // 统计
  statsOverview: () => request('GET', '/api/stats/overview'),
  /** @param {string[]} [excludeIds] 本轮已看过的 id，见 03 §3.7 */
  random: (type = 'inspiration', excludeIds = []) =>
    request('GET', `/api/stats/random${qs({ type, exclude: excludeIds })}`),
};

/** 路径段编码。UUID 本身无需编码，但 title 等若被误传入路径就会出问题。 */
function enc(s) { return encodeURIComponent(String(s)); }
```

### 4.3.1 `exclude` 参数的编码问题

`api.random(type, ['id1','id2'])` 经 `qs()` 会拼成 `exclude=id1%2Cid2`（逗号被编码为 `%2C`）。`URLSearchParams` 在后端解析时会正确还原为 `id1,id2`，因此**无需特殊处理**。

但若 id 数量很大（比如遍历了 80 条知识点），URL 会超过 8 KB 触发某些服务器的长度限制。**应对**：前端在 exclude 超过 50 个时直接清空重新开一轮，而不是继续累加：

```js
if (this.seen.length > 50) this.seen = [];
```

这个阈值远小于任何类别的常见条目数，实际很少触发；触发时用户只是"重新开始一轮随机"，无感知。

## 4.4 DOM 工具层（`js/dom.js`）

**核心原则：不使用字符串拼接 HTML 插入用户内容**（XSS 风险，见 §4.9）。所有元素用 `el()` 构造，文本走 `textContent`。

```js
/* ============================================================
   dom.js —— DOM 构造与格式化工具
   ============================================================ */

/**
 * 创建元素。
 * @param {string} tag
 * @param {object} [props]  class/attrs/on/style/text/children
 * @returns {HTMLElement}
 *
 * 用法：
 *   el('button', { class:'btn', text:'保存', on:{ click: save } })
 *   el('div', { class:'card', children:[ el('h3',{text:'标题'}), el('p',{text:'正文'}) ] })
 */
export function el(tag, props = {}) {
  const node = document.createElement(tag);
  for (const [k, v] of Object.entries(props)) {
    if (v === null || v === undefined || v === false) continue;
    switch (k) {
      case 'class':
        // 支持 'a b c' 字符串或 ['a','b'] 数组，自动过滤假值
        node.className = (Array.isArray(v) ? v : String(v).split(/\s+/))
                           .filter(Boolean).join(' ');
        break;
      case 'text':    node.textContent = String(v); break;   // ★ 文本一律 textContent
      case 'html':    node.innerHTML = v; break;              // 仅限已净化的内容，见 §4.9
      case 'style':   Object.assign(node.style, v); break;
      case 'on':      for (const [ev, fn] of Object.entries(v)) node.addEventListener(ev, fn); break;
      case 'attrs':   for (const [a, val] of Object.entries(v)) {
                        if (val !== null && val !== undefined) node.setAttribute(a, val);
                      } break;
      case 'children': (Array.isArray(v) ? v : [v]).filter(Boolean)
                        .forEach(c => node.append(c)); break;
      default:        node[k] = v;   // value / checked / disabled / href 等直接属性
    }
  }
  return node;
}

/** 批量创建后一次性插入，避免多次重排。 */
export function frag(children) {
  const f = document.createDocumentFragment();
  children.filter(Boolean).forEach(c => f.append(c));
  return f;
}

/** 清空容器后填入新内容。 */
export function render(container, children) {
  container.replaceChildren(...(Array.isArray(children) ? children : [children]));
}

/** 防抖。搜索框输入用（见 §4.6）。 */
export function debounce(fn, wait = 250) {
  let t;
  return function (...args) {
    clearTimeout(t);
    t = setTimeout(() => fn.apply(this, args), wait);
  };
}

// ============ 格式化 ============

/** 金额：分 → 元字符串，千分位，两位小数。见 01 §1.5.2。 */
export function yuan(cents) {
  const n = Number(cents || 0) / 100;
  return n.toLocaleString('zh-CN', { minimumFractionDigits: 2, maximumFractionDigits: 2 });
}

/** 元 → 分。用 Math.round 规避 19.99*100=1998.9999… */
export function toCents(yuanStr) {
  const n = parseFloat(String(yuanStr).replace(/[,，\s]/g, ''));
  if (!Number.isFinite(n) || n < 0) return null;
  return Math.round(n * 100);
}

/**
 * 相对时间：「刚刚」「5 分钟前」「3 天前」「2026-09-28」。
 * 超过 30 天回落到绝对日期——太久远的事情说"3 个月前"没有信息量。
 */
export function relTime(iso) {
  if (!iso) return '';
  const t = new Date(iso).getTime();
  if (Number.isNaN(t)) return '';
  const diff = Date.now() - t;
  const min = 60_000, hour = 60 * min, day = 24 * hour;

  if (diff < min)        return '刚刚';
  if (diff < hour)       return `${Math.floor(diff / min)} 分钟前`;
  if (diff < day)        return `${Math.floor(diff / hour)} 小时前`;
  if (diff < 7 * day)    return `${Math.floor(diff / day)} 天前`;
  if (diff < 30 * day)   return `${Math.floor(diff / (7 * day))} 周前`;
  return iso.slice(0, 10);   // ISO 串前 10 位即 yyyy-MM-dd
}

/** 完整时间：2026-10-02 14:23。用于 title 提示与详情页元信息。 */
export function fullTime(iso) {
  if (!iso) return '';
  const d = new Date(iso);
  if (Number.isNaN(d.getTime())) return '';
  const p = n => String(n).padStart(2, '0');
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())} ${p(d.getHours())}:${p(d.getMinutes())}`;
}

/** 摘要：Markdown 源码 → 纯文本前两行，用于列表项。 */
export function excerpt(md, maxLen = 120) {
  if (!md) return '';
  const plain = String(md)
    .replace(/```[\s\S]*?```/g, ' ')      // 代码块整段去掉
    .replace(/`([^`]*)`/g, '$1')          // 行内代码保留内容
    .replace(/!\[[^\]]*\]\([^)]*\)/g, '') // 图片整个去掉
    .replace(/\[([^\]]*)\]\([^)]*\)/g, '$1') // 链接保留文字
    .replace(/^\s{0,3}#{1,6}\s+/gm, '')   // 标题标记
    .replace(/^\s{0,3}>\s?/gm, '')        // 引用标记
    .replace(/^\s{0,3}[-*+]\s+/gm, '')    // 无序列表标记
    .replace(/^\s{0,3}\d+\.\s+/gm, '')    // 有序列表标记
    .replace(/[*_~]{1,3}/g, '')           // 强调标记
    .replace(/\$\$?[\s\S]*?\$\$?/g, ' ')  // 数学公式（本项目不渲染，去掉避免乱码）
    .replace(/\s+/g, ' ')
    .trim();
  return plain.length > maxLen ? plain.slice(0, maxLen) + '…' : plain;
}

/** 学科路径拆分：'数学/线性代数' → ['数学','线性代数'] */
export function subjectParts(path) {
  return path ? String(path).split('/').filter(Boolean) : [];
}
```

## 4.5 主题切换（`js/theme.js`）

```js
/* ============================================================
   theme.js —— 明暗主题。在 <head> 内联调用以避免闪烁（FOUC）。
   ============================================================ */

const KEY = 'pouch-theme';

/** 应用主题。写 documentElement 的 data-theme。 */
export function applyTheme(mode) {
  document.documentElement.setAttribute('data-theme', mode);
}

/**
 * 初始化：优先用户手动选择，其次系统偏好。
 * 必须在 body 渲染前调用，否则会看到一瞬间的错误主题。
 */
export function initTheme() {
  const saved = localStorage.getItem(KEY);
  if (saved === 'light' || saved === 'dark') { applyTheme(saved); return saved; }

  const prefersDark = window.matchMedia?.('(prefers-color-scheme: dark)').matches;
  const mode = prefersDark ? 'dark' : 'light';
  applyTheme(mode);   // 显式写入，让 CSS 只需维护 :root 与 [data-theme=dark] 两套

  // 用户未手动选择时，持续跟随系统切换
  window.matchMedia?.('(prefers-color-scheme: dark)')
    .addEventListener('change', e => {
      if (!localStorage.getItem(KEY)) applyTheme(e.matches ? 'dark' : 'light');
    });
  return mode;
}

/** 切换并持久化。返回新主题。 */
export function toggleTheme() {
  const cur = document.documentElement.getAttribute('data-theme') === 'dark' ? 'dark' : 'light';
  const next = cur === 'dark' ? 'light' : 'dark';
  applyTheme(next);
  localStorage.setItem(KEY, next);   // 一旦手动选择，就不再跟随系统
  return next;
}

/** 顶栏按钮：图标随主题变化，aria-label 同步更新（无障碍）。 */
export function mountThemeToggle(container) {
  const btn = document.createElement('button');
  btn.className = 'icon-btn';
  btn.type = 'button';
  const sync = () => {
    const dark = document.documentElement.getAttribute('data-theme') === 'dark';
    btn.textContent = dark ? '☀' : '☾';
    btn.setAttribute('aria-label', dark ? '切换到浅色主题' : '切换到深色主题');
    btn.title = btn.getAttribute('aria-label');
  };
  btn.addEventListener('click', () => { toggleTheme(); sync(); });
  sync();
  container.append(btn);
}
```

**避免 FOUC（闪烁）**：三个页面的 `<head>` 中都应内联一段极短脚本，在 CSS 之后、body 之前执行：

```html
<script type="module">
  import { initTheme } from '/js/theme.js';
  initTheme();
</script>
```

> **`type="module"` 是 defer 语义**，会在 HTML 解析完成后才执行，仍可能闪一下。**更稳妥的做法是把 `initTheme` 的核心三行内联为非 module 脚本**：
>
> ```html
> <script>
>   (function(){
>     var s = localStorage.getItem('pouch-theme');
>     var m = (s === 'light' || s === 'dark') ? s
>           : (window.matchMedia && window.matchMedia('(prefers-color-scheme: dark)').matches ? 'dark' : 'light');
>     document.documentElement.setAttribute('data-theme', m);
>   })();
> </script>
> ```
>
> 放在 `<head>` 中 CSS `<link>` **之后**。这段代码与 `theme.js` 的逻辑重复，但为了避免闪烁值得——**修改主题逻辑时必须同步改这两处**，在 `theme.js` 顶部注释里写明这一点。

> **Chart.js 的颜色必须从 CSS 变量读取**（`getComputedStyle`），不能在 JS 里写死十六进制值。否则切换主题时图表颜色不会变。
>
> **主题切换后需要重绘图表**：Chart.js 的颜色是从 CSS 变量读的（`getComputedStyle`），变量值在图表创建时就固化进 canvas 了，切主题不会自动生效。做法是在 `theme.js` 的切换函数里派发一个自定义事件，首页监听后用上一次的统计数据重绘：
>
> ```js
> // theme.js 的 toggleTheme 末尾
> document.dispatchEvent(new CustomEvent('pouch:themechange', { detail: { mode: next } }));
>
> // index.js 顶部：缓存最近一次统计结果，供重绘使用
> let lastStats = null;
>
> // index.js 的 loadOverview 中，拿到数据后立即缓存
> const s = await api.statsOverview();
> lastStats = s;
>
> // index.js 监听主题变化
> document.addEventListener('pouch:themechange', () => { if (lastStats) renderCompletion(lastStats); });
> ```
>
> **只重绘图表，不重新请求 API**——`lastStats` 的意义正在于此。否则每次切主题都会多发一次请求，且在服务未启动时会把一个正常的主题切换变成错误提示。

```js
    submit.disabled = true;
    try {
      const res = await api.addWish({ name: nameInput.value.trim(), amountCents: cents });
      // 响应含更新后的 summary，无需再发 GET（03 §3.5）
      renderWishSummary(document.getElementById('wishSummary'), res.summary);
      document.getElementById('wishList').append(wishRow(res.item));
      // 清掉可能存在的空状态提示
      document.querySelector('#wishList .empty-hint')?.remove();
      form.reset();
      nameInput.focus();
    } catch (err) {
      toast(err.message);
    } finally {
      submit.disabled = false;
    }
  });
}

async function loadRandom(type) {
  const box = document.getElementById(type + 'Body');
  box.classList.add('is-loading');
  try {
    const data = await api.random(type, seen[type]);

    if (data.exhausted) seen[type] = [];      // 服务端已重开一轮（03 §3.7）
    if (data.record) {
      seen[type].push(data.record.id);
      if (seen[type].length > SEEN_LIMIT) seen[type] = [];
    }
    renderRecall(type, box, data);
  } catch (e) {
    render(box, errorCard('加载失败', e));
  } finally {
    box.classList.remove('is-loading');
  }
}
```

```js
function dueBadge(r) {
  const due = new Date(r.dueDate + 'T23:59:59');   // 当日结束才算过期
```

```js
async function flipStatus(r, newStatus, input) {
  input.disabled = true;
  try {
    await api.updateRecord(r.id, { status: newStatus }, r.type);
    r.status = newStatus;
    // 局部更新这一行的状态徽标，不重绘整个列表（保持滚动位置）
    const row = input.closest('.row');
    const badge = row.querySelector('[class*="badge-status-"]');
    if (badge) {
      badge.className = `badge badge-status-${newStatus}`;
      badge.textContent = statusLabel(catOf(r.type), newStatus);
    }
    // 若当前正按状态筛选，这条已不符合条件 → 淡出后移除
    if (state.status?.includes(newStatus) === false) {
      row.classList.add('is-leaving');
      setTimeout(() => { row.remove(); refreshOverviewCounts(); }, 250);
    }
  } catch (e) {
    input.checked = !input.checked;   // 失败回滚 UI
    toast(e.message);
  } finally {
    input.disabled = false;
  }
}
```

### 4.8.2 Markdown 渲染与安全

**这是本项目唯一的 XSS 风险点**，必须处理（详见 §4.9）。

```js
import { marked } from '/vendor/marked.min.js';   // 或作为全局变量使用

/**
 * 渲染 Markdown 为 HTML。
 * ★ 必须配合 DOMPurify 或等效净化——marked 不做任何过滤。
 */
function renderMarkdown(src) {
  if (!src) return '';
  marked.setOptions({
    gfm: true,          // GitHub 风格：表格、删除线、任务列表
    breaks: true,       // 单个换行转 <br>，符合随手记录的书写习惯
    headerIds: false,   // 不生成 id，避免与页面元素冲突
    mangle: false,
  });
  const raw = marked.parse(src);
  return DOMPurify.sanitize(raw, {
    // 允许链接与代码，禁止一切脚本与事件属性
    ALLOWED_TAGS: ['p','br','strong','em','del','code','pre','blockquote',
                   'ul','ol','li','h1','h2','h3','h4','h5','h6',
                   'a','hr','table','thead','tbody','tr','th','td','span','img'],
    ALLOWED_ATTR: ['href','title','src','alt','class'],
    // ★ 禁止 javascript: 等危险协议（DOMPurify 默认已阻止，显式声明以防配置漂移）
    ALLOWED_URI_REGEXP: /^(?:(?:https?|mailto):|[^a-z]|[a-z+.\-]+(?:[^a-z+.\-:]|$))/i,
  });
}
```

> **DOMPurify 是必需的第三方依赖**，需与 Chart.js、marked 一起 vendor 到 `web/vendor/purify.min.js`——共 3 个前端 vendor 文件。获取方式见 [05 §5.2](./05-开发计划与运维.md#52-依赖获取清单)。
>
> 若确实不想引入 DOMPurify，替代方案是**不用 `innerHTML`**：解析 Markdown 为 AST 后用 `el()` 逐节点构造。这需要写约 150 行的 AST→DOM 转换器，且要跟随 marked 版本维护。**引入 DOMPurify（约 20 KB）是明显更优的选择**。

## 4.9 安全注意事项

前端涉及用户输入的回显，以下四条必须遵守。

### 4.9.1 XSS：唯一的真实风险点

**风险场景**：用户在正文里写 `<img src=x onerror="alert(1)">`，若直接用 `innerHTML` 插入，脚本会执行。单用户本地应用里"攻击自己"看似无害，但真实风险在于——**用户可能从网上复制一段含恶意 HTML 的内容粘进笔记**，之后每次打开这条记录都会执行。

**三条防线**：

| 防线 | 做法 | 位置 |
|---|---|---|
| 1. 默认用 `textContent` | `el()` 的 `text` 属性走 `textContent`，天然免疫 | `dom.js` §4.4 |
| 2. Markdown 必须净化 | `marked.parse()` 结果经 `DOMPurify.sanitize()` 后才进 `innerHTML` | `detail.js` §4.8.2 |
| 3. `html` 属性集中管控 | `el()` 的 `html` 分支是唯一允许 `innerHTML` 的地方，代码审查时只需搜这一处 | `dom.js` §4.4 |

**代码审查规则**：全项目搜索 `innerHTML`，只应出现两处——`dom.js` 的 `el()` 实现，以及净化函数内部。任何第三处都是 bug。

### 4.9.2 URL 参数注入

`detail.html?id=xxx` 的 `id` 来自 URL，**不可信**。

```js
// ✗ 错误：直接拼进 HTML
box.innerHTML = `<p>找不到记录 ${id}</p>`;

// ✓ 正确：走 textContent
render(box, [el('p', { text: `找不到记录 ${id}` })]);

// ✓ 拼进 API 路径时必须编码（api.js 的 enc() 已处理）
api.getRecord(id);
```

`from` 参数同理——它是**完整 URL**，若直接 `location.href = from` 就构成开放重定向。虽然本地应用危害有限，仍应校验：

```js
const safeBack = (from) => {
  if (!from) return '/list.html';
  const decoded = decodeURIComponent(from);
  // 只允许站内相对路径，拒绝 //evil.com 和 http:// 开头的
  return decoded.startsWith('/') && !decoded.startsWith('//') ? decoded : '/list.html';
};
```

### 4.9.3 请求体大小

前端不做限制，后端限制 2 MB（03 §3.0.1）。但**前端应在提交前给出友好提示**，而不是等后端返回 400：

```js
const MAX_CONTENT = 100_000;   // 与后端一致（01 §1.9）
if (content.length > MAX_CONTENT) {
  toast(`正文过长（${content.length} 字符），上限 ${MAX_CONTENT} 字符`);
  return;
}
```

### 4.9.4 失败时的状态保持

这是**用户体验层面的安全**，但重要性等同：

| 场景 | 正确行为 | 错误行为 |
|---|---|---|
| 保存记录返回 500 | 保留 textarea 内容，提示重试 | 清空表单 / 退回只读态 |
| 添加笔记失败 | 保留输入框内容 | 清空输入框 |
| 切换状态失败 | 复选框回滚到原状态 | 停留在用户点的位置（与数据不一致） |
| 删除失败 | 条目保留 | 条目已从 UI 移除但数据还在 |

**统一原则：UI 状态只能在服务端确认成功后才变更。** 乐观更新（先改 UI 再发请求）在本项目中只对"切换状态"这类低风险操作使用，且**必须实现失败回滚**（见 §4.6.2 `wishRow` 与 §4.7.2 `flipStatus`）。

## 4.10 无障碍（a11y）要点

不是可选项。学习工具的使用时长往往很长，键盘操作和屏幕阅读器支持直接影响可用性。

| 项 | 做法 |
|---|---|
| 语义标签 | `<header>` `<nav>` `<main>` `<article>` `<section>` `<time>` 按语义使用，不全是 `<div>` |
| 焦点可见 | 全局 `:focus-visible` 样式（`base.css`），**不得写 `outline: none` 而不提供替代** |
| 图标按钮 | 必须有 `aria-label`（如主题切换、标签删除的 `×`） |
| 表单关联 | 每个 `<input>` 有 `<label for>` 或 `aria-label` |
| 动态内容 | toast 容器 `role="status" aria-live="polite"`；告警横幅 `role="alert"` |
| 状态传达 | 复选框的选中态由 `checked` 属性表达（屏幕阅读器可读），不能只靠颜色 |
| 颜色对比 | 见 §4.2.1，正文 ≥4.5:1 |
| 键盘可达 | 列表项是 `<a>`，Tab 可聚焦，Enter 可进入详情 |
| 减少动效 | `@media (prefers-reduced-motion: reduce)` 关闭过渡（`tokens.css` 已含） |
| 语言声明 | `<html lang="zh-CN">`，影响屏幕阅读器发音 |

**`base.css` 中的焦点样式**：

```css
/* 只对键盘聚焦显示焦点环，鼠标点击不显示（避免视觉噪音） */
:focus-visible {
  outline: var(--ring-w) solid var(--accent);
  outline-offset: var(--ring-offset);
  border-radius: var(--r-sm);
}
/* 绝不使用 outline: none。若需自定义，必须提供等效可见样式 */
```
